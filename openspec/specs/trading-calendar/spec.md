# trading-calendar Specification

## Purpose

为交易侧和案件侧提供纽交所的交易日和常规交易时段：哪天开市，几点开盘、几点收盘（UTC），某天之后第 N 个交易日是哪天，某个时刻是否在盘中。所有计算都是确定性的，不受进程时区和当前时间影响；超出数据范围时报错，不返回错误的答案。

## Requirements

### Requirement: 用交易时段构造日历

日历 SHALL 用一段连续日期区间里的全部交易时段构造，交易时段按交易日的顺序传入。每个交易时段包含三项：

- 交易日：美东日期
- 常规时段的开盘时间：带时区的 UTC 时间
- 常规时段的收盘时间：带时区的 UTC 时间

区间内没有出现的日期一律视为休市。日历的覆盖范围从第一个交易日到最后一个交易日，日历 SHALL 提供这两端的交易时段。

#### Scenario: 覆盖范围是第一个到最后一个交易日

- **GIVEN** 纽交所 2026-10-01 到 2026-12-31 的全部交易时段
- **WHEN** 构造日历
- **THEN** 覆盖范围的第一个交易日是 2026-10-01，最后一个是 2026-12-31

### Requirement: 按日期判断交易日

给定一个日期，日历 SHALL 回答它是不是交易日，并给出这天的交易时段；不是交易日时，交易时段为"无"。

本节以及后面两节的场景里，"纽交所日历"指用纽交所 2026-09-01 到 2027-01-29 的全部交易时段构造的日历。

#### Scenario: 普通交易日

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-01
- **THEN** 是交易日，开盘 13:30Z，收盘 20:00Z

#### Scenario: 银行假日照常开市

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-12（哥伦布日）
- **THEN** 是交易日

#### Scenario: 周末和节假日

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-03（周六）和 2026-11-26（感恩节）
- **THEN** 都不是交易日，交易时段为"无"

#### Scenario: 半日市

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-11-27
- **THEN** 是交易日，开盘 14:30Z，收盘 18:00Z

### Requirement: 按日期推算交易日

日历 SHALL 支持以下四种推算。起点日期不必是交易日：

| 推算 | 结果 |
| --- | --- |
| 某日之后的第一个交易日 | 不含当天 |
| 某日之前的最后一个交易日 | 不含当天 |
| 某日之后第 n 个交易日 | n 至少为 1；第 1 个就是"之后的第一个交易日" |
| 两个日期之间的交易日个数 | 不含起点，含终点；起点不晚于终点 |

#### Scenario: 之后的第一个交易日跳过节假日

- **GIVEN** 纽交所日历
- **WHEN** 求 2026-11-25 之后的第一个交易日
- **THEN** 得到 2026-11-27

#### Scenario: 从周末开始推算

- **GIVEN** 纽交所日历
- **WHEN** 求 2026-10-03（周六）之后的第一个交易日
- **THEN** 得到 2026-10-05

#### Scenario: 之前的最后一个交易日

- **GIVEN** 纽交所日历
- **WHEN** 求 2026-11-30 之前的最后一个交易日
- **THEN** 得到 2026-11-27

#### Scenario: 之后第 n 个交易日

- **GIVEN** 纽交所日历
- **WHEN** 求 2026-10-05 之后第 5 个交易日
- **THEN** 得到 2026-10-12

#### Scenario: 从节假日开始数

- **GIVEN** 纽交所日历
- **WHEN** 求 2026-11-26（感恩节）之后第 1 个交易日
- **THEN** 得到 2026-11-27

#### Scenario: 跨年

- **GIVEN** 纽交所日历
- **WHEN** 求 2026-12-31 之后第 1 个交易日
- **THEN** 得到 2027-01-04

#### Scenario: 两个日期之间的交易日个数

- **GIVEN** 纽交所日历
- **WHEN** 计数 2026-10-05 到 2026-10-12、2026-11-26 到 2026-11-28、2026-10-05 到 2026-10-05
- **THEN** 分别是 5、1、0

#### Scenario: 推算和计数互逆

- **GIVEN** 任意交易时段数据构造的日历，覆盖范围内的任意日期 d，以及任意 n ≥ 1，并且 d 之后第 n 个交易日仍在数据范围内
- **WHEN** 求 d 之后第 n 个交易日 e，再计数 d 到 e
- **THEN** 计数结果等于 n

### Requirement: 按时刻判断交易时段

给定一个带时区的时刻，日历 SHALL 回答三个问题：

| 问题 | 结果 |
| --- | --- |
| 这个时刻所在的常规交易时段 | 不在盘中时为"无" |
| 下一个开盘的交易时段 | 开盘时间晚于这个时刻的第一个时段 |
| 最近一个已收盘的交易时段 | 收盘时间不晚于这个时刻的最后一个时段 |

常规时段按左闭右开计算：开盘那一刻算盘中，收盘那一刻不算。

#### Scenario: 盘中

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-01T15:00:00Z
- **THEN** 所在时段是 2026-10-01；下一个开盘的是 2026-10-02；最近已收盘的是 2026-09-30

#### Scenario: 开盘那一刻算盘中

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-01T13:30:00Z
- **THEN** 所在时段是 2026-10-01

#### Scenario: 开盘前一微秒不算盘中

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-01T13:29:59.999999Z
- **THEN** 不在盘中；下一个开盘的是 2026-10-01，开盘 13:30Z

#### Scenario: 收盘那一刻不算盘中

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-01T20:00:00Z
- **THEN** 不在盘中；最近已收盘的是 2026-10-01

#### Scenario: 半日市提前收盘

- **GIVEN** 纽交所日历
- **WHEN** 分别查询 2026-11-27T17:59:59Z 和 2026-11-27T18:00:00Z
- **THEN** 前者在 2026-11-27 的时段内，后者不在盘中

#### Scenario: UTC 日期和美东日期不是同一天

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-02T00:30:00Z，也就是美东时间 2026-10-01 20:30
- **THEN** 不在盘中；最近已收盘的是 2026-10-01；下一个开盘的是 2026-10-02，开盘 13:30Z

#### Scenario: 夏令时结束

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-30T20:00:00Z（周五收盘）
- **THEN** 下一个开盘的是 2026-11-02，开盘 14:30Z

#### Scenario: 周末

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-03T12:00:00Z（周六）
- **THEN** 不在盘中；最近已收盘的是 2026-10-02；下一个开盘的是 2026-10-05

#### Scenario: 任意时刻要么在盘中，要么在两个相邻时段之间

- **GIVEN** 任意交易时段数据构造的日历，以及第二个时段开盘到倒数第二个时段收盘之间的任意时刻 t
- **WHEN** 查询 t
- **THEN** 要么 t 在某个时段内（开盘 ≤ t < 收盘）；要么 t 不在盘中，最近已收盘的时段和下一个开盘的时段在数据里相邻，并且前者的收盘 ≤ t < 后者的开盘

### Requirement: 超出覆盖范围的查询报错

数据范围之外的问题，日历 MUST 报覆盖范围错误（CalendarRangeError），不能返回根据现有数据推测出的答案。以下情况都算超出范围：

- 查询的日期不在第一个交易日到最后一个交易日之间
- 查询的时刻早于第一个交易日的开盘，或者不早于最后一个交易日的收盘
- 答案落在数据之外

#### Scenario: 日期超出覆盖范围

- **GIVEN** 纽交所 2026-10-01 到 2026-12-31 的交易时段构造的日历
- **WHEN** 判断 2026-09-30 是不是交易日，或者计数 2026-12-01 到 2027-01-04
- **THEN** 都报覆盖范围错误

#### Scenario: 推算结果超出数据范围

- **GIVEN** 纽交所 2026-10-01 到 2026-12-31 的交易时段构造的日历
- **WHEN** 求 2026-12-31 之后的第一个交易日、2026-12-01 之后第 60 个交易日，或者 2026-10-01 之前的最后一个交易日
- **THEN** 都报覆盖范围错误

#### Scenario: 时刻或它的答案超出数据范围

- **GIVEN** 纽交所 2026-10-01 到 2026-12-31 的交易时段构造的日历
- **WHEN** 查询 2026-09-30T15:00:00Z；或者查询 2026-12-31T15:00:00Z 的下一个开盘；或者查询 2026-10-01T15:00:00Z 的最近已收盘
- **THEN** 都报覆盖范围错误

### Requirement: 加载纽交所的交易时段

系统 SHALL 从交易所日历数据加载纽交所（XNYS）在给定起止日期之间（含两端）的全部交易时段，并构造日历。纳斯达克上市的股票使用同一套交易日和常规时段。

加载要满足以下要求：

- 起止日期 MUST 由调用方给出
- 加载结果 MUST 只取决于起止日期，不受加载时刻和进程时区影响
- 开盘和收盘 MUST 换算成 UTC 时区

加载范围可以配置，默认值如下（M2 接线时写进配置）：

| 项 | 默认值 | 理由 |
| --- | --- | --- |
| 起点 | 2020-01-01 | 覆盖系统上线前后用到的历史 |
| 终点 | 启动时往后 730 天 | 远超最长的前瞻（60 个交易日，约 3 个月），进程连续运行一年多也不会用完 |

本节场景都在 UTC+14 的进程里运行，加载范围是 2025-01-01 到 2027-12-31。

#### Scenario: 2026 年的休市日与纽交所公告一致

- **WHEN** 加载纽交所日历
- **THEN** 以下日期都不是交易日：2026-01-01、2026-01-19、2026-02-16、2026-04-03、2026-05-25、2026-06-19、2026-07-03、2026-09-07、2026-11-26、2026-12-25

#### Scenario: 节日落在周末时的补休

- **WHEN** 加载纽交所日历
- **THEN** 以下日期休市：2026-07-03（7 月 4 日是周六）、2027-06-18、2027-07-05、2027-12-24
- **AND** 2027-12-31 照常开市，因为 2028 年元旦是周六，不在前一个周五补休

#### Scenario: 半日市

- **WHEN** 加载纽交所日历
- **THEN** 2026-11-27、2026-12-24、2027-11-26 都在 18:00Z 收盘
- **AND** 2026-07-02 全天交易，在 20:00Z 收盘

#### Scenario: 夏令时切换

- **WHEN** 加载纽交所日历
- **THEN** 开盘时间分别是：2026-03-06 为 14:30Z，2026-03-09 为 13:30Z，2026-10-30 为 13:30Z，2026-11-02 为 14:30Z

#### Scenario: 已收录的临时休市

- **WHEN** 加载纽交所日历
- **THEN** 2025-01-09（卡特国葬日）不是交易日

#### Scenario: 银行假日照常开市

- **WHEN** 加载纽交所日历
- **THEN** 2026-10-12（哥伦布日）和 2026-11-11（退伍军人节）都是交易日

### Requirement: 时刻归属的交易日

给定一个带时区的时刻，日历 SHALL 给出它归属的交易日：收盘时间晚于这个时刻的第一个交易时段。于是一个交易日从上一个交易日收盘（含）到这个交易日收盘（不含），周末和休市日并进下一个交易日。案件侧按天计的规则（比如股票池每天的增删次数）用它划分"每天"；和降级模式的"恢复后的第一个交易日"是同一条规则。

| 时刻 | 归属的交易日 |
| --- | --- |
| 交易日盘前 | 当天 |
| 盘中 | 当天 |
| 收盘时刻或之后 | 下一个交易日 |
| 休市日 | 之后的第一个交易日 |

时刻超出覆盖范围时报覆盖范围错误，见「超出覆盖范围的查询报错」。

#### Scenario: 盘前和盘中归属当天

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-14T12:00:00Z（盘前）和 2026-10-14T19:59:59Z（盘中）
- **THEN** 归属的交易日都是 2026-10-14

#### Scenario: 收盘时刻或之后归属下一个交易日

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-14T20:00:00Z（收盘）和 2026-10-15T03:00:00Z（美东时间 2026-10-14 晚上）
- **THEN** 归属的交易日都是 2026-10-15
- **WHEN** 查询 2026-11-27T18:00:00Z（感恩节次日提前收盘的收盘时刻）
- **THEN** 归属的交易日是 2026-11-30

#### Scenario: 休市日归属之后的第一个交易日

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-17T15:00:00Z（周六）
- **THEN** 归属的交易日是 2026-10-19
- **WHEN** 查询 2026-11-26T15:00:00Z（感恩节）
- **THEN** 归属的交易日是 2026-11-27

#### Scenario: 归属的交易日是所在时段或下一个开盘的时段

- **GIVEN** 任意交易时段数据构造的日历，以及覆盖范围内（第一个时段开盘到最后一个时段收盘之前）的任意时刻 t
- **WHEN** 查询 t 归属的交易日
- **THEN** t 在盘中时是所在时段的交易日，否则是下一个开盘的时段的交易日

#### Scenario: 时刻超出覆盖范围

- **GIVEN** 纽交所 2026-10-01 到 2026-12-31 的交易时段构造的日历
- **WHEN** 查询 2026-09-30T15:00:00Z 或 2026-12-31T21:00:00Z 归属的交易日
- **THEN** 都报覆盖范围错误
