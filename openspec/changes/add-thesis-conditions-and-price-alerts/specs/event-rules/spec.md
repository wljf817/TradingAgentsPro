# Spec Delta

## MODIFIED Requirements

### Requirement: 事件的内容

一个事件 SHALL 有下面这些项：

| 项 | 内容 |
| --- | --- |
| 事件 ID | 见「事件 ID 和去重」 |
| 股票 | 股票代码 |
| 类别 | case-types spec「事件要求的子 agent」的事件类别：价格和成交量异动、新闻、公告、财报发布、入场条件满足、达到目标价或证伪条件触发 |
| 持仓风险级别 | 是或否，只有持仓的事件可以是 |
| 来源 | 行情、新闻源、公告源、财报日历之一；论点条件是行情 |
| 强度 | 价格异动是涨跌幅（下跌为负，四舍五入到 4 位小数）；成交量异动是量比；新闻和公告是级别：1 一般、2 重大；财报发布和论点条件没有 |
| 发生时刻 | 价格、成交量和论点条件是行情的更新时刻；新闻是发布时刻；公告是受理时刻；财报日历是预计发布时刻（见「财报发布」） |
| 检测时刻 | 检测出这个事件的那一轮开始时从时钟读的时刻（event-detection spec「一轮」） |
| 说明 | 中文，写明事件的内容，见下 |
| 引用 | 新闻是新闻 ID；公告和 8-K 的财报发布是 accession number；财报日历的财报发布是财报发布的键（company-data spec，比如 AAA:2027Q2）；价格、成交量和论点条件没有 |
| 处理 | 排队；或者交给紧急风险退出、不排队（只有持仓跌幅达到紧急阈值的价格下跌事件） |

说明 SHALL 写明：价格异动的涨跌方向和幅度、最新价、参考价和它是哪一种（前一交易日收盘价或今天开仓成交的均价）、阈值，持仓风险级别的写明紧急阈值，交给紧急风险退出的写明；成交量异动的量比和阈值；新闻的标题、命中的关键词和级别、是否负面；公告的表单和 item、级别、是否负面；财报发布的 8-K 的 accession number，或者财报日历上这次发布的财年季度、发布日、发布时段和预计发布时刻；论点条件是哪一组（入场条件、目标价、证伪条件）、满足的每一条条件和它比较的量这时的值（最新价、当日涨跌幅或当日累计成交量）。

本 spec 的场景除非另有说明，都使用默认配置和下面的基准数据：

- 当前时刻 2026-10-14 15:00Z（周三，盘中；当天 13:30Z 开盘、20:00Z 收盘），交易日历是纽交所日历；检测时刻是当前时刻，今天（检测时刻归属的交易日）是 2026-10-14
- 股票池：AAA 是候选，BBB 是关注，CCC 是持仓，都在 2026-10-01 加入；CCC 的紧急阈值 0.08，今天没有开仓成交
- 行情：三只股票的前一交易日收盘价都是 100，最新价 100，量比 1，当日累计成交量 1,000,000 股，更新时刻 2026-10-14 14:59:58Z；"CCC 最新价 x"指只把 CCC 的最新价改为 x
- "标题 t 的新闻"指一条只标注这只股票、稿件来源 benzinga、发布时刻 2026-10-14 14:50Z、标题是 t 的新闻，新闻 ID 101；"表单 f 的公告"指一份只标注这只股票、受理时刻 2026-10-14 14:50Z、表单是 f 的公告，accession number 0000000001-26-000001，8-K 另写 item
- 没有说明时，股票这个交易日还没有任何事件

#### Scenario: 持仓风险级别的价格下跌事件

- **WHEN** CCC 最新价 95.5，判断 CCC 的价格
- **THEN** 有一个事件：事件 ID CCC:2026-10-14:price_down，股票 CCC，类别价格和成交量异动，持仓风险级别，来源行情，强度 -0.045，发生时刻 2026-10-14 14:59:58Z，检测时刻 2026-10-14 15:00Z，没有引用，处理是排队
- **AND** 说明写明跌 4.5%、最新价 95.5、参考价 100 是前一交易日收盘价、阈值 4%、紧急阈值 8%

#### Scenario: 新闻事件的内容

- **WHEN** 判断 BBB 的标题"BBB to Acquire Widget Co"的新闻
- **THEN** 有一个事件：事件 ID BBB:2026-10-14:news，类别新闻，不是持仓风险级别，来源新闻源，强度 2，发生时刻 2026-10-14 14:50Z，引用新闻 ID 101，处理是排队
- **AND** 说明写明标题、命中的关键词 acqui、重大、不是负面

#### Scenario: 入场条件满足事件的内容

- **GIVEN** BBB 的关注论点的入场条件是价格不高于 95、成交量不低于 5,000,000 股
- **WHEN** BBB 最新价 94.5，判断 BBB 的论点条件
- **THEN** 有一个事件：事件 ID BBB:2026-10-14:entry，类别入场条件满足，不是持仓风险级别，来源行情，没有强度，发生时刻 2026-10-14 14:59:58Z，检测时刻 2026-10-14 15:00Z，没有引用，处理是排队
- **AND** 说明写明入场条件、满足的条件"价格不高于 95"和最新价 94.5；没写成交量那一条

### Requirement: 事件 ID 和去重

事件 ID SHALL 由股票、交易日和下表的种类组成，写成 `<股票>:<交易日>:<种类>`，比如 `CCC:2026-10-14:price_down`；交易日是检测时刻归属的交易日（trading-calendar spec：盘前和盘中是当天，收盘以后和休市日是之后的第一个交易日）。同一个事件 ID SHALL 只有一个事件：已经有这个事件 ID 的事件时，新的不是事件。

| 种类 | 事件 | 另外的规则 |
| --- | --- | --- |
| price_up | 价格上涨 | |
| price_down | 价格下跌，包括交给紧急风险退出的 | |
| volume | 成交量异动 | |
| news | 新闻或公告，不是持仓风险级别的 | 当天已经有这只股票的财报发布事件时不是事件，原因是当天已有财报发布事件 |
| news_risk | 新闻或公告，持仓风险级别的 | 同上 |
| earnings | 财报发布 | 见「财报发布」的间隔 |
| entry | 入场条件满足 | |
| target | 达到目标价 | |
| invalidation | 证伪条件触发 | |

- 所以价格上涨、价格下跌、成交量异动、入场条件满足、达到目标价、证伪条件触发每只股票每个交易日最多各一个；新闻和公告合起来每只股票每个交易日最多一个普通的、一个持仓风险级别的
- 新闻或公告因为事件 ID 已经有了而没有成为事件时，原因是当天已有新闻或公告事件
- 当天更早的新闻或公告事件不挡财报发布事件
- 各种类互不相挡：同一只股票同一天可以既有价格下跌事件又有证伪条件触发事件

#### Scenario: 同一天同一类只有一个

- **GIVEN** CCC 最新价 95.5 时有了 CCC:2026-10-14:price_down
- **WHEN** 之后 CCC 最新价 93，再判断 CCC 的价格
- **THEN** 没有新的事件
- **WHEN** CCC 最新价 106
- **THEN** 有 CCC:2026-10-14:price_up

#### Scenario: 交给紧急退出的也挡住当天的下跌

- **GIVEN** CCC 最新价 92 时有了交给紧急风险退出的 CCC:2026-10-14:price_down；之后 CCC 清仓，变为候选
- **WHEN** CCC 最新价 91，判断 CCC 的价格
- **THEN** 没有新的事件

#### Scenario: 第二天重新算

- **GIVEN** 有 CCC:2026-10-14:price_down
- **WHEN** 检测时刻 2026-10-15 14:00Z，CCC 前一交易日收盘价 95，最新价 91，更新时刻 2026-10-15 13:59:58Z
- **THEN** 有 CCC:2026-10-15:price_down

#### Scenario: 收盘以后的新闻算下一个交易日

- **WHEN** 检测时刻 2026-10-14 21:00Z，判断 BBB 的标题"BBB to Acquire Widget Co"的新闻
- **THEN** 有新闻事件，事件 ID BBB:2026-10-15:news

#### Scenario: 新闻和公告合起来一天一个

- **GIVEN** 有 BBB:2026-10-14:news（一条新闻）
- **WHEN** 判断 BBB 的表单 10-Q 的公告；判断 BBB 的标题"BBB CEO Steps Down"的新闻
- **THEN** 都没有事件，原因是当天已有新闻或公告事件

#### Scenario: 持仓风险的新闻和公告另算

- **GIVEN** 有 CCC:2026-10-14:news
- **WHEN** 判断 CCC 的标题"CCC Faces Class Action Lawsuit"的新闻
- **THEN** 有 CCC:2026-10-14:news_risk
- **WHEN** 再判断 CCC 的表单 S-3 的公告
- **THEN** 没有事件，原因是当天已有新闻或公告事件

#### Scenario: 财报发布以后当天的新闻不算

- **GIVEN** 有 BBB:2026-10-14:earnings
- **WHEN** 判断 BBB 的标题"BBB Raises FY26 Guidance"的新闻
- **THEN** 没有事件，原因是当天已有财报发布事件
- **GIVEN** 有 CCC:2026-10-14:earnings
- **WHEN** 判断 CCC 的标题"CCC Lowers Guidance"的新闻
- **THEN** 没有事件，原因是当天已有财报发布事件

#### Scenario: 更早的新闻不挡财报发布

- **GIVEN** 有 BBB:2026-10-14:news
- **WHEN** 判断 BBB 的 8-K，item 2.02
- **THEN** 有 BBB:2026-10-14:earnings

#### Scenario: 条件一直满足时每天一个

- **GIVEN** BBB 的入场条件是价格不高于 95；有 BBB:2026-10-14:entry
- **WHEN** BBB 最新价 93，再判断 BBB 的论点条件
- **THEN** 没有新的事件
- **WHEN** 检测时刻 2026-10-15 14:00Z，BBB 最新价 94，更新时刻 2026-10-15 13:59:58Z
- **THEN** 有 BBB:2026-10-15:entry

#### Scenario: 价格下跌不挡证伪条件

- **GIVEN** CCC 的证伪条件中代码能检测的部分是价格不高于 95；有 CCC:2026-10-14:price_down
- **WHEN** CCC 最新价 94.5，判断 CCC 的论点条件
- **THEN** 有 CCC:2026-10-14:invalidation

## ADDED Requirements

### Requirement: 论点条件

一只股票的论点条件 SHALL 按它这时的状态和股票池里它的论点，分组用下表判断；一组里任一条件满足，就是这一组的一个事件：

| 股票状态 | 组 | 条件 | 事件 | 类别 | 种类 | 持仓风险级别 |
| --- | --- | --- | --- | --- | --- | --- |
| 关注 | 入场条件 | 关注论点的入场条件 | 入场条件满足 | 入场条件满足 | entry | 否 |
| 持仓 | 目标价 | 价格不低于投资论点的目标价 | 达到目标价 | 达到目标价或证伪条件触发 | target | 否 |
| 持仓 | 证伪条件 | 投资论点的证伪条件中代码能检测的部分；没有时这一组不判断 | 证伪条件触发 | 达到目标价或证伪条件触发 | invalidation | 是 |

一条条件（stock-pool spec「关注论点的格式」的三类）按下表算满足：

| 类型 | 不低于 v | 不高于 v |
| --- | --- | --- |
| 价格 | 最新价 ≥ v | 最新价 ≤ v |
| 涨跌幅 | 最新价 ≥ 前一交易日收盘价 ×（1 + v） | 最新价 ≤ 前一交易日收盘价 ×（1 + v） |
| 成交量 | 当日累计成交量 ≥ v | 不存在（格式不允许） |

- 涨跌幅从前一交易日收盘价算，持仓今天有开仓成交也一样；用乘法比较，不先算出涨跌幅
- 候选没有论点，不判断；`/plan` 买入、不在股票池里的持仓不是监控股票（event-detection spec「监控范围」）
- 只在「行情要是当天的」满足时判断；成交量条件不等「成交量开始判断」
- 行情没有当日累计成交量时，成交量条件不满足
- 处理都是排队，包括持仓跌幅同时达到紧急阈值时的证伪条件触发事件
- 条件没满足不是事件，也不写程序日志

本 requirement 的场景另外使用：BBB 的关注论点的入场条件是价格不高于 95；CCC 的投资论点目标价 120，证伪条件中代码能检测的部分是价格不高于 94。

#### Scenario: 入场条件的价格

- **WHEN** BBB 最新价 95；BBB 最新价 95.01
- **THEN** 95 时有 BBB 的入场条件满足事件，事件 ID BBB:2026-10-14:entry，不是持仓风险级别；95.01 时没有事件

#### Scenario: 入场条件任一满足

- **GIVEN** BBB 的入场条件改为：价格不高于 90、涨跌幅不低于 0.03、成交量不低于 2,000,000 股
- **WHEN** BBB 最新价 103；102.99；当日累计成交量 2,000,000 股；1,999,999 股
- **THEN** 103 时有入场条件满足事件，说明只写涨跌幅那一条；102.99 时没有事件；成交量 2,000,000 股时有入场条件满足事件；1,999,999 股时没有事件

#### Scenario: 涨跌幅不高于负数

- **GIVEN** BBB 的入场条件改为涨跌幅不高于 -0.05
- **WHEN** BBB 最新价 95；95.01
- **THEN** 95 时有入场条件满足事件；95.01 时没有事件

#### Scenario: 达到目标价

- **WHEN** CCC 最新价 120；CCC 最新价 119.99
- **THEN** 120 时有 CCC 的达到目标价事件：事件 ID CCC:2026-10-14:target，类别达到目标价或证伪条件触发，不是持仓风险级别，处理是排队；119.99 时没有事件

#### Scenario: 证伪条件触发

- **WHEN** CCC 最新价 94；CCC 最新价 94.01
- **THEN** 94 时有 CCC 的证伪条件触发事件：事件 ID CCC:2026-10-14:invalidation，类别达到目标价或证伪条件触发，持仓风险级别，处理是排队；94.01 时没有事件

#### Scenario: 证伪条件和紧急阈值同时越过

- **WHEN** CCC 最新价 91
- **THEN** 有 CCC 的证伪条件触发事件，处理是排队

#### Scenario: 没有代码能检测的证伪条件

- **GIVEN** CCC 的证伪条件中代码能检测的部分没有条件
- **WHEN** CCC 最新价 80
- **THEN** 没有证伪条件触发事件

#### Scenario: 候选不判断

- **WHEN** AAA 最新价 50
- **THEN** AAA 没有论点条件的事件

#### Scenario: 行情不是当天的

- **WHEN** 检测时刻 2026-10-14 12:00Z，BBB 最新价 90
- **THEN** 没有入场条件满足事件
- **GIVEN** BBB 没有最新价
- **WHEN** 检测时刻 2026-10-14 15:00Z
- **THEN** 没有入场条件满足事件
- **GIVEN** BBB 的行情更新时刻 2026-10-14 13:29:58Z，最新价 90
- **WHEN** 判断 BBB 的论点条件
- **THEN** 没有入场条件满足事件

#### Scenario: 成交量条件不等开盘 30 分钟

- **GIVEN** BBB 的入场条件改为成交量不低于 500,000 股；BBB 的行情更新时刻 2026-10-14 13:40:00Z
- **WHEN** 检测时刻 2026-10-14 13:40:01Z，判断 BBB 的论点条件
- **THEN** 有入场条件满足事件
