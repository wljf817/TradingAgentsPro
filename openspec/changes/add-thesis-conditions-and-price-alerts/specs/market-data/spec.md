# Spec Delta

## MODIFIED Requirements

### Requirement: 取行情

行情模块 SHALL 按调用方给出的一组股票，向行情源取这些股票的行情，每只股票最多一条。一只股票的行情包括：

| 项 | 含义 |
| --- | --- |
| 股票 | 股票代码，比如 AAPL |
| 最新价 | 当前交易日常规交易时段的最新成交价；开盘以前、开盘后的头 1 分钟，以及当天开盘后这只股票还没有成交时，没有最新价 |
| 前一交易日收盘价 | 前一个交易日常规交易时段的收盘价 |
| 量比 | 行情源算好的量比：当天常规交易时段平均每分钟的成交量，和过去 5 个交易日平均每分钟的成交量之比；没有最新价时也没有量比 |
| 成交量 | 当天常规交易时段的累计成交量（股，整数）；没有最新价时也没有成交量 |
| 更新时刻 | 行情源最近一次更新这只股票行情的时刻，UTC |

盘前、盘后的成交不算最新价：系统只在常规交易时段下单和判断。开盘后的头 1 分钟也不给最新价：行情源这时给的最新价可能还是前一交易日的收盘价。

- 行情源没有某只股票的数据时，结果里没有这只股票
- 没有给出股票时，结果为空，不向行情源取
- 同一只股票给出多次，只向行情源取一次
- 行情源超时、断线或出错时，报行情不可用；行情模块不重试，下一次调用再取

本 spec 的场景除非另有说明，都使用默认配置和下面的基准数据：

- 行情源有这些股票的数据：
  - AAA：最新价 105.5，前一交易日收盘价 100，量比 1.8，成交量 2,345,670，更新时刻 2026-10-14 14:59:59.500Z
  - BBB：没有最新价（今天开盘后还没有成交），前一交易日收盘价 50，没有量比，没有成交量，更新时刻 2026-10-14 13:29:58Z
  - SPY：最新价 580.25，前一交易日收盘价 578.1，量比 0.95，成交量 35,734,306，更新时刻 2026-10-14 14:59:59.900Z
- 行情源没有 CCC 的数据

#### Scenario: 取两只股票

- **GIVEN** 基准数据
- **WHEN** 取 AAA、BBB 的行情
- **THEN** 结果有两条：AAA 最新价 105.5、前一交易日收盘价 100、量比 1.8、成交量 2,345,670、更新时刻 2026-10-14 14:59:59.500Z；BBB 没有最新价、前一交易日收盘价 50、没有量比、没有成交量、更新时刻 2026-10-14 13:29:58Z

#### Scenario: 行情源没有的股票

- **GIVEN** 基准数据
- **WHEN** 取 AAA、CCC 的行情
- **THEN** 结果只有 AAA 一条

#### Scenario: 没有给出股票

- **GIVEN** 基准数据
- **WHEN** 取行情，没有给出任何股票
- **THEN** 结果为空
- **AND** 没有向行情源取

#### Scenario: 同一只股票给出多次

- **GIVEN** 基准数据
- **WHEN** 取 AAA、AAA、BBB 的行情
- **THEN** 向行情源取的股票是 AAA、BBB，各一次
- **AND** 结果有 AAA、BBB 两条

#### Scenario: 行情源不可用

- **GIVEN** 行情源超时、断线或出错
- **WHEN** 取 AAA 的行情
- **THEN** 报行情不可用
