# Spec Delta

## MODIFIED Requirements

### Requirement: 程序日志的条目

程序 SHALL 把每个动作写成程序日志的一条记录。程序日志存在状态库所在的数据库里（表 `programlog_entries`，state-store spec「表的归属和迁移」），只由程序日志模块写入：别的模块、流程和启动程序都经它写，不直接写表。每条记录有：

| 字段 | 内容 |
| --- | --- |
| 编号 | 按写入的先后递增 |
| 时间 | 写入时从时钟读取的时刻；存为带时区的时刻，读回的是同一时刻，和数据库服务器、本机的时区都无关 |
| 行为者 | 风控引擎、执行模块、人、系统、股票池，各自的动作见下面以「<行为者>的动作」为名的要求；以后的变更加别的行为者和动作 |
| 动作 | 行为者的一个动作 |
| 对象 | 动作针对的东西的标识：方案 ID、止损单的客户端订单 ID、股票代码；针对整个券商账户写 `account`，针对整个程序写 `system` |
| 案件 ID | 动作所属的案件；不属于案件时为空 |
| 输入的引用、输出的引用 | 动作用到的、产生的东西的标识，比如确认消息的标识、交易日；各是一组文字，可以为空 |
| 说明 | 动作的内容和结果，中文；可以为空 |
| 耗时、token、费用 | 可以为空；费用是金额，原样保存每一位小数 |

行为者和动作各是一组固定的值。案件 ID、耗时、token 和费用只在动作的要求写明时才有，其余为空。

#### Scenario: 写一条

- **GIVEN** 进程的本机时区是 UTC+14；时钟是 2026-10-14T15:00:00.123Z
- **WHEN** 写一条：行为者是人，动作是确认，对象是方案 ID P1，输入的引用是确认消息的标识 M1，说明是"买入 BBB"
- **THEN** 程序日志多了一条，读回的时间是 2026-10-14T15:00:00.123Z，行为者、动作、对象、输入的引用和说明都是写入的值
- **AND** 输出的引用为空，案件 ID、耗时、token、费用为空

#### Scenario: 可以为空的字段原样读回

- **WHEN** 写一条带案件 ID、耗时 1.5 秒、token 1200、费用 0.0123 的条目
- **THEN** 读回的案件 ID、耗时、token 和费用都和写入的相同，费用仍是 0.0123

## ADDED Requirements

### Requirement: 股票池的动作

股票池的下面这些动作 SHALL 各写一条，行为者是股票池，对象是股票代码，没有引用：

| 动作 | 什么时候写 | 说明 |
| --- | --- | --- |
| 加入 | 每次加入请求（PM 探索、手动添加），通过和被拒绝都写 | 来源和理由；通过时写板块和过期时间，被拒绝时写原因 |
| 删除 | 每次删除请求 | 理由；通过时写移出前的状态，被拒绝时写原因 |
| 升级 | 每次升级请求 | 通过时写关注论点的复查日、催化剂截止日期和上次复查的那一天；被拒绝时写原因 |
| 降为候选 | 每次降为候选请求 | 通过时写过期时间；被拒绝时写原因 |
| 保持 | 每次保持请求 | 通过时写新的过期时间；被拒绝时写原因 |
| 记录评分 | 每次记录评分 | 评分；被拒绝时写原因 |
| 论点更新 | 每次关注论点或投资论点的更新 | 哪一种论点；通过时写复查日、催化剂截止日期和上次复查的那一天，被拒绝时写原因 |
| 超期移出 | 移出到期的候选，每只一条 | 过期时间 |
| 买入成交 | 候选或关注买入成交，变为持仓 | 原来的状态；投资论点的复查日、催化剂截止日期和上次复查的那一天 |
| 清仓 | 代码触发的清仓；PM 发起的清仓完成 | 谁发起的和去向：转为候选写过期时间；转为关注写关注论点的复查日、催化剂截止日期和上次复查的那一天；移出 |

- 案件 ID：PM 发起的操作（加入、删除、升级、降为候选、保持、记录评分、论点更新）写调用方给出的案件 ID；手动添加、超期移出、买入成交和清仓不属于案件，为空
- 通过的操作在记录保存以后写；被拒绝的请求不改变记录，只写条目
- 记录没有变化的 SHALL NOT 写：持仓后续的买入成交
- 代码发起的操作遇到不对的状态、评分超出范围时报错，是程序的错误，SHALL NOT 写程序日志（「不写进程序日志的」里的技术问题）
- 写条目出错时照「写入失败」：操作报错，已经保存的记录不撤回

场景使用 stock-pool spec 的基准数据；PM 发起的操作都属于案件 K1。

#### Scenario: 加入通过

- **WHEN** 加入 DDD
- **THEN** 程序日志有一条加入，行为者是股票池，对象 DDD，案件 ID K1
- **AND** 说明写明通过、PM 探索、理由"放量突破，论点草稿：订单回暖"、板块"科技"、过期时间 2026-10-28 20:00 UTC

#### Scenario: 加入被拒绝

- **WHEN** 加入 AAA
- **THEN** 程序日志有一条加入，对象 AAA，案件 ID K1，说明写明被拒绝、已在池子里
- **AND** AAA 的记录不变

#### Scenario: 手动添加没有案件 ID

- **WHEN** 手动添加 DDD
- **THEN** 程序日志有一条加入，对象 DDD，说明写明通过、手动添加，没有案件 ID

#### Scenario: 删除

- **WHEN** 删除 AAA；删除 CCC
- **THEN** 程序日志有两条删除：AAA 的说明写明通过、理由"论点不再成立"、移出前是候选；CCC 的说明写明被拒绝、持仓不能删除

#### Scenario: 升级

- **WHEN** 以基准关注论点升级 AAA，上次复查的那一天 2026-10-14
- **THEN** 程序日志有一条升级，对象 AAA，案件 ID K1，说明写明通过、复查日 2026-10-21、催化剂截止日期 2026-10-29、上次复查的那一天 2026-10-14

#### Scenario: 降为候选和保持

- **WHEN** BBB 降为候选；保持 CCC
- **THEN** 程序日志有一条降为候选，对象 BBB，说明写明通过、过期时间 2026-10-28 20:00 UTC
- **AND** 有一条保持，对象 CCC，说明写明被拒绝、状态不允许

#### Scenario: 记录评分

- **WHEN** 记录 AAA 的评分 1；记录 ZZZ 的评分 1
- **THEN** 程序日志有一条记录评分，对象 AAA，案件 ID K1，说明写明评分 1
- **AND** 有一条记录评分，对象 ZZZ，说明写明被拒绝、不在池子里

#### Scenario: 论点更新

- **WHEN** 更新 CCC 的投资论点：基准投资论点的复查日改为 2026-10-23，上次复查的那一天 2026-10-07
- **THEN** 程序日志有一条论点更新，对象 CCC，案件 ID K1，说明写明投资论点、通过、复查日 2026-10-23、催化剂截止日期 2026-10-29、上次复查的那一天 2026-10-07

#### Scenario: 超期移出

- **WHEN** 当前时刻 2026-10-27 20:00Z，移出到期的候选
- **THEN** 程序日志有一条超期移出，对象 AAA，没有案件 ID，说明写明过期时间 2026-10-27 20:00 UTC

#### Scenario: 买入成交

- **WHEN** BBB 买入成交
- **THEN** 程序日志有一条买入成交，对象 BBB，没有案件 ID，说明写明原来是关注、复查日 2026-10-21、催化剂截止日期 2026-10-29、上次复查的那一天 2026-10-14

#### Scenario: 持仓后续的买入成交不写

- **WHEN** CCC 买入成交
- **THEN** 程序日志没有新条目

#### Scenario: 代码触发的清仓

- **WHEN** CCC 的止损单成交，代码触发的清仓
- **THEN** 程序日志有一条清仓，对象 CCC，没有案件 ID，说明写明代码触发、转为候选、过期时间 2026-10-28 20:00 UTC

#### Scenario: PM 发起的清仓转为关注

- **WHEN** CCC 由 PM 发起的清仓完成，PM 选择转为关注
- **THEN** 程序日志有一条清仓，对象 CCC，没有案件 ID，说明写明 PM 发起、转为关注、复查日 2026-10-21、催化剂截止日期 2026-10-29、上次复查的那一天 2026-10-14

#### Scenario: PM 发起的清仓后移出

- **WHEN** CCC 由 PM 发起的清仓完成，PM 选择移出
- **THEN** 程序日志有一条清仓，对象 CCC，没有案件 ID，说明写明 PM 发起、移出

#### Scenario: 报错的操作不写

- **WHEN** ZZZ 买入成交；记录 AAA 的评分 3
- **THEN** 都报错，程序日志没有新条目

#### Scenario: 写条目出错

- **GIVEN** 写程序日志时数据库会出错
- **WHEN** 加入 DDD
- **THEN** 报错
- **AND** DDD 在池子里，是候选
