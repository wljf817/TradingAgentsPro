# Spec Delta

## ADDED Requirements

### Requirement: 已经结束的卖出

执行模块 SHALL 按一个交易日 D 给出已经结束的卖出：类型是卖出或止损单、状态是全部成交、已撤销或已过期、累计成交大于 0、成交日不早于 D 的交易记录，按成交日、再按客户端订单 ID 排列。

- 只读交易记录，不调用券商
- 还没结束的（待提交、已提交、部分成交、状态未知）不给出：结束以后再给出
- 读出错时照 state-store spec「读写出错时报错」报错

#### Scenario: 已经结束、有成交的卖出

- **GIVEN** 交易记录：P5 卖出 AAA，全部成交，累计成交 60，成交日 2026-10-14；BBB-STOP-1 止损单，全部成交，累计成交 100，成交日 2026-10-14；P6 卖出 CCC，已过期，累计成交 40，成交日 2026-10-13；P1 买入 BBB，全部成交，成交日 2026-10-13
- **WHEN** 按交易日 2026-10-13 读已经结束的卖出
- **THEN** 依次是 P6、BBB-STOP-1、P5
- **WHEN** 按交易日 2026-10-14 读
- **THEN** 依次是 BBB-STOP-1、P5

#### Scenario: 没结束或没成交的不给出

- **GIVEN** 交易记录：P5 卖出 AAA，部分成交，累计成交 20；BBB-STOP-1 止损单，挂着，累计成交 40，状态部分成交；P6 卖出 CCC，已撤销，累计成交 0
- **WHEN** 按交易日 2026-10-13 读已经结束的卖出
- **THEN** 为空
