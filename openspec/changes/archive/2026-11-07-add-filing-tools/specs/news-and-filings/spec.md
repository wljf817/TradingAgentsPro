## MODIFIED Requirements

### Requirement: 取公告

模块 SHALL 按调用方给出的一组股票和起始时刻，向公告源取这些股票所属公司起始时刻（含）以来被 SEC 受理的公告，然后：

- 调用方给出结束时刻时，只留受理时刻不晚于结束时刻（含）的；给出表单类型时，只留表单类型在里面的。留下的才存、才返回
- 把还没存过的公告存下：按 accession number 判断，已经存过的 MUST NOT 再写入，也 MUST NOT 修改
- 返回这次新存下的公告，按受理时刻排序，受理时刻相同的按 accession number 排序
- 公告源这次给出的结果里同一个 accession number 出现几次，只存一次、返回一次
- 没有给出股票时，结果为空，不向公告源取
- 同一只股票给出多次，只向公告源问一次
- 公告源超时、断线、限频或出错时，报数据源不可用，这次什么都不存；模块不重试

公告源对哪些股票查不到公司，见 sec-filings spec「股票代码到 CIK」；模块不区分，只存公告源给出的。

#### Scenario: 第一次取公告

- **GIVEN** 公告源对 AAA、BBB 给出 F3、F2、F1；还没有存过公告
- **WHEN** 取 AAA、BBB 自 2026-10-14 00:00Z 的公告
- **THEN** 公告源被问到的是 AAA、BBB，起始时刻 2026-10-14 00:00Z
- **AND** 存下 F1、F2、F3，返回 F1、F2、F3，按这个顺序

#### Scenario: 再取一次只返回新的公告

- **GIVEN** 已经存过 F1；公告源给出 F1、F2
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 的公告
- **THEN** 存下 F2，返回只有 F2

#### Scenario: 没有给出股票时不取公告

- **WHEN** 取公告，没有给出任何股票
- **THEN** 结果为空
- **AND** 没有向公告源取

#### Scenario: 公告源不可用

- **GIVEN** 公告源这次报数据源不可用
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 的公告
- **THEN** 报数据源不可用
- **AND** 什么都没有存

#### Scenario: 给出结束时刻

- **GIVEN** 公告源对 AAA、BBB 给出 F1、F2、F3；还没有存过公告
- **WHEN** 取 AAA、BBB 自 2026-10-14 00:00Z、到 2026-10-14 21:59:59Z 的公告
- **THEN** 存下 F1，返回只有 F1；没有存 F2、F3
- **WHEN** 再取 AAA、BBB 自 2026-10-14 00:00Z、到 2026-10-14 22:00:00Z 的公告
- **THEN** 存下 F2，返回只有 F2；没有存 F3

#### Scenario: 给出表单类型

- **GIVEN** 公告源对 AAA、BBB 给出 F1、F2、F3；还没有存过公告
- **WHEN** 取 AAA、BBB 自 2026-10-14 00:00Z 的公告，表单类型是 8-K 和 10-Q
- **THEN** 存下 F1、F3，返回 F1、F3；没有存 F2

### Requirement: 新闻和公告的存储

模块 SHALL 把新闻和公告存在状态库所在的数据库里（新闻表 news_articles、公告表 news_filings、公告文件表 news_filing_documents，state-store spec「表的归属和迁移」），只由本模块写入：

- 只追加：一条新闻、一份公告、公告的一个文件各一行，写入以后 MUST NOT 被修改或删除；每行带写入时刻，从时钟读取
- 读回的新闻和公告和写入的完全相同：正文里的 HTML 和中文、没有的链接、标注的股票和 item 的顺序；发布时刻、受理时刻读回的是同一时刻，和数据库服务器、本机的时区都无关
- 进程重启以后（用同一个数据库新建存储），SHALL 读到之前存下的全部条目，之后取到的照样按 ID 去重
- 两个调用同时取到同一条新闻或公告时，SHALL 只存一行，并且只有一个调用把它当作新存下的返回
- 读写出错（数据库连不上、表不存在、存着的条目读不出来）时 SHALL 报错：MUST NOT 当作没有条目返回空，也 MUST NOT 当作已经存下

#### Scenario: 原样读回

- **GIVEN** 进程的本机时区是 UTC+14
- **WHEN** 2026-10-14 15:00:00Z 取到并存下 N1、N2 和 F1，再读 AAA 自 2026-10-14 00:00Z 的新闻和公告
- **THEN** 读到的 N1、N2、F1 和存下的完全相同：N1 的正文仍是 `<p>AAA 上调全年指引</p>`，N2 仍然没有链接、标注的股票仍依次是 AAA、BBB，F1 的 item 仍依次是 2.02、9.01，发布时刻和受理时刻不变
- **AND** 新闻表里 N1、N2 的写入时刻和公告表里 F1 的写入时刻都是 2026-10-14 15:00:00Z

#### Scenario: 重启以后接着去重

- **GIVEN** 已经存下 N1
- **WHEN** 重启，新闻源给出 N1、N2，取 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 返回只有 N2，N1 仍然只有一行

#### Scenario: 同时取到同一条

- **GIVEN** 还没有存过新闻；新闻源对两个调用都给出 N1
- **WHEN** 两个调用同时取 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 新闻表里 N1 只有一行
- **AND** 一个调用返回 N1，另一个返回为空

#### Scenario: 读写出错

- **GIVEN** 数据库连不上
- **WHEN** 取 AAA 的新闻；或者读 AAA 的公告
- **THEN** 都报错，读不返回空
- **GIVEN** 空数据库，没有升级
- **WHEN** 读 AAA 的新闻
- **THEN** 报错
- **GIVEN** 新闻表里 N1 那一行缺了必填的标题
- **WHEN** 读 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 报错，不跳过 N1

#### Scenario: 公告的文件原样读回

- **GIVEN** 进程的本机时区是 UTC+14；已经存下 F1
- **WHEN** 2026-10-14 21:00:00Z 存下 F1 的文件：8-K `aaa-8k.htm` 文字"封面"，EX-99.1 `ex991.htm` 文字"营收 1.2 亿 ’Q3’"，再读 F1 的文件
- **THEN** 读到的两个文件和存下的完全相同，顺序不变
- **AND** 公告文件表里这两行的写入时刻都是 2026-10-14 21:00:00Z

## ADDED Requirements

### Requirement: 按 accession number 读一份公告

模块 SHALL 能按 accession number 读出已经存下的那份公告；没有时结果为空，不向公告源取。

#### Scenario: 读到公告

- **GIVEN** 已经存下 F1
- **WHEN** 读 0000000001-26-000001
- **THEN** 读到 F1，和存下的完全相同

#### Scenario: 没有这份公告

- **GIVEN** 已经存下 F1
- **WHEN** 读 0000000009-26-000009
- **THEN** 结果为空
- **AND** 没有向公告源取

### Requirement: 公告的文件

模块 SHALL 能给出一份已经存下的公告的文件：每个文件有文件类型、文件名和纯文本，按公告里的顺序，第一个是主文件（sec-filings spec「公告的文件」）。

- 状态库已经存下这份公告的文件时，SHALL 直接读出，MUST NOT 向公告源取
- 还没有存下时，向公告源取一次，把全部文件存下再返回；之后 MUST NOT 再取
- 公告源给出的文件列表是空的时，结果为空，什么都不存
- 公告源超时、断线、限频或出错时，报数据源不可用，这次什么都不存；模块不重试
- 两个调用同时第一次取同一份公告的文件时，每个文件 SHALL 只存一行，两个调用都返回全部文件

#### Scenario: 第一次取文件

- **GIVEN** 已经存下 F1；公告源对 F1 给出 8-K `aaa-8k.htm` 和 EX-99.1 `ex991.htm`
- **WHEN** 取 F1 的文件
- **THEN** 返回这两个文件，主文件在前
- **AND** 两个文件存进了状态库

#### Scenario: 再取只读状态库

- **GIVEN** 已经存下 F1 和它的两个文件
- **WHEN** 取 F1 的文件
- **THEN** 返回这两个文件
- **AND** 没有向公告源取

#### Scenario: 没有能读的文件

- **GIVEN** 已经存下 F1；公告源对 F1 给出空的文件列表
- **WHEN** 取 F1 的文件
- **THEN** 结果为空，什么都没有存
- **WHEN** 再取 F1 的文件
- **THEN** 又向公告源取了一次

#### Scenario: 取文件时公告源不可用

- **GIVEN** 已经存下 F1；公告源这次报数据源不可用
- **WHEN** 取 F1 的文件
- **THEN** 报数据源不可用，什么都没有存

#### Scenario: 同时第一次取同一份公告的文件

- **GIVEN** 已经存下 F1；公告源对两个调用都给出 8-K `aaa-8k.htm` 和 EX-99.1 `ex991.htm`
- **WHEN** 两个调用同时取 F1 的文件
- **THEN** 公告文件表里这两个文件各只有一行
- **AND** 两个调用都返回这两个文件
