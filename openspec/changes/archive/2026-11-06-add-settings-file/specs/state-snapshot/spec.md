# Spec Delta

## MODIFIED Requirements

### Requirement: 快照配置

快照的配置项 SHALL 可配置，默认值如下：

| 配置项 | 默认值 | 要求 | 含义 |
| --- | --- | --- | --- |
| 指数 | SPY、QQQ、VIXY | 至少一个，每个都不为空 | 每份快照都带它们的行情 |
| 新闻回看的交易日数 | 5 | 正整数 | 见「案件股票的事实」的回看起点 |
| 公告回看的交易日数 | 65 | 正整数 | 同上；65 个交易日约是一个季度，盖住最近一份 10-Q |

不满足要求时 MUST 配置报错。

本 spec 其他 Requirement 的场景，指数都配置为 SPY、QQQ。

#### Scenario: 默认配置

- **WHEN** 不传任何配置项新建配置
- **THEN** 指数是 SPY、QQQ、VIXY，新闻回看 5 个交易日，公告回看 65 个交易日

#### Scenario: 配置不合法

- **WHEN** 指数配置为空；指数里有空的股票代码；新闻回看的交易日数配置为 0；公告回看的交易日数配置为 0
- **THEN** 都配置报错

#### Scenario: 改配置

- **GIVEN** 指数配置为只有 SPY，新闻回看的交易日数配置为 3
- **WHEN** 生成 K-1 的第 1 版
- **THEN** 没有 s1/quote/QQQ 和 s1/quote/VIXY
- **AND** 新闻的回看起点是 2026-10-09 20:00Z：只有 N3
