# Spec Delta

## ADDED Requirements

### Requirement: 时刻归属的交易日

给定一个带时区的时刻，日历 SHALL 给出它归属的交易日：收盘时间晚于这个时刻的第一个交易时段。于是一个交易日从上一个交易日收盘（含）到这个交易日收盘（不含），周末和休市日并进下一个交易日。案件侧按天计的规则（比如股票池每天的增删次数）用它划分"每天"；和降级模式的"恢复后的第一个交易日"是同一条规则。

| 时刻 | 归属的交易日 |
| --- | --- |
| 交易日盘前 | 当天 |
| 盘中 | 当天 |
| 收盘时刻或之后 | 下一个交易日 |
| 休市日 | 之后的第一个交易日 |

时刻超出覆盖范围时报覆盖范围错误，见「超出覆盖范围的查询报错」。

#### Scenario: 盘前和盘中归属当天

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-14T12:00:00Z（盘前）和 2026-10-14T19:59:59Z（盘中）
- **THEN** 归属的交易日都是 2026-10-14

#### Scenario: 收盘时刻或之后归属下一个交易日

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-14T20:00:00Z（收盘）和 2026-10-15T03:00:00Z（美东时间 2026-10-14 晚上）
- **THEN** 归属的交易日都是 2026-10-15
- **WHEN** 查询 2026-11-27T18:00:00Z（感恩节次日提前收盘的收盘时刻）
- **THEN** 归属的交易日是 2026-11-30

#### Scenario: 休市日归属之后的第一个交易日

- **GIVEN** 纽交所日历
- **WHEN** 查询 2026-10-17T15:00:00Z（周六）
- **THEN** 归属的交易日是 2026-10-19
- **WHEN** 查询 2026-11-26T15:00:00Z（感恩节）
- **THEN** 归属的交易日是 2026-11-27

#### Scenario: 归属的交易日是所在时段或下一个开盘的时段

- **GIVEN** 任意交易时段数据构造的日历，以及覆盖范围内（第一个时段开盘到最后一个时段收盘之前）的任意时刻 t
- **WHEN** 查询 t 归属的交易日
- **THEN** t 在盘中时是所在时段的交易日，否则是下一个开盘的时段的交易日

#### Scenario: 时刻超出覆盖范围

- **GIVEN** 纽交所 2026-10-01 到 2026-12-31 的交易时段构造的日历
- **WHEN** 查询 2026-09-30T15:00:00Z 或 2026-12-31T21:00:00Z 归属的交易日
- **THEN** 都报覆盖范围错误
