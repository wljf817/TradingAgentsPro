## ADDED Requirements

### Requirement: 续期上限

关注股连续续期没有开仓时 SHALL 受续期上限限制。续期指 review-dates spec「检查论点里的日期」的续期：关注复查和关注催化剂复查里继续关注附的论点更新。

- 开得了仓：本案件快照的可用额度（case-headroom spec）里，可用资金不低于最小下单额，并且持仓名额大于 0
- 到上限：连续续期次数（stock-pool spec「股票池的记录」）不小于续期上限，并且开得了仓

| 开得了仓 | 连续续期次数 | 能继续关注 | 这次续期计入次数 |
| --- | --- | --- | --- |
| 是 | 小于上限 | 能 | 计入 |
| 是 | 不小于上限 | 不能 | 没有这次续期 |
| 否 | 任何次数 | 能 | 不计入 |

续期上限 SHALL 是可配置项，默认值 3，MUST 至少 1，否则配置报错。

本 requirement 的场景里，可用资金 1,000 美元，最小下单额 400 美元，持仓名额 2 只；续期上限 3。

#### Scenario: 没到上限

- **GIVEN** BBB 的连续续期次数是上限减 1
- **WHEN** 判断 BBB
- **THEN** 没到上限，这次续期计入

#### Scenario: 到上限

- **GIVEN** BBB 的连续续期次数等于上限；或者大于上限
- **WHEN** 判断 BBB
- **THEN** 都到上限

#### Scenario: 可用资金的边界

- **GIVEN** BBB 的连续续期次数等于上限
- **WHEN** 可用资金是 400 美元
- **THEN** 开得了仓，到上限
- **WHEN** 可用资金是 399.99 美元
- **THEN** 开不了仓，没到上限，这次续期不计入

#### Scenario: 持仓名额的边界

- **GIVEN** BBB 的连续续期次数等于上限
- **WHEN** 持仓名额是 1
- **THEN** 开得了仓，到上限
- **WHEN** 持仓名额是 0
- **THEN** 开不了仓，没到上限，这次续期不计入

#### Scenario: 没到上限时开不了仓也不计入

- **GIVEN** BBB 的连续续期次数是 1，持仓名额是 0
- **WHEN** 判断 BBB
- **THEN** 没到上限，这次续期不计入

#### Scenario: 默认配置

- **WHEN** 不传任何配置项新建配置
- **THEN** 续期上限是 3

#### Scenario: 配置不合法

- **WHEN** 续期上限配置为 0
- **THEN** 配置报错

## MODIFIED Requirements

### Requirement: 关注的结论

关注的结论 SHALL 有一个决定，按下表附带其他内容；不符合下表、或者决定不是这四种，都是格式错误：

| 决定 | 交易方案 | 投资论点 | 论点更新 | 跟进申请 | 什么变了 |
| --- | --- | --- | --- | --- | --- |
| 开仓方案 | 必须写，动作是买入 | 必须附 | 不写 | 不写 | 不写 |
| 继续关注 | 不写 | 不写 | 可以附 | 可以附 | 可以写 |
| 降为候选 | 不写 | 不写 | 不写 | 不写 | 可以写 |
| 移出 | 不写 | 不写 | 不写 | 不写 | 可以写 |

- 投资论点是新建仓的论点（见「投资论点的格式」）
- 论点更新是一份完整的关注论点，代替原来的关注论点
- 移出股票池的理由就是结论的理由
- 什么变了是文字，写明为什么没有照承诺开仓；只有空白是格式错误。哪些案件必须写见「结论的校验」

#### Scenario: 开仓方案

- **WHEN** 决定开仓方案，写基准方案条款，附基准投资论点
- **THEN** 格式正确
- **WHEN** 决定开仓方案，写基准方案条款，不附投资论点
- **THEN** 格式错误
- **WHEN** 决定开仓方案，附基准投资论点，不写交易方案
- **THEN** 格式错误
- **WHEN** 决定开仓方案，写基准方案条款，附基准投资论点，另外附基准关注论点作为论点更新，或者附基准跟进申请
- **THEN** 都是格式错误

#### Scenario: 继续关注

- **WHEN** 决定继续关注，不附任何内容
- **THEN** 格式正确
- **WHEN** 决定继续关注，附基准关注论点作为论点更新，附基准跟进申请
- **THEN** 格式正确
- **WHEN** 决定继续关注，写了基准方案条款
- **THEN** 格式错误

#### Scenario: 降为候选和移出

- **WHEN** 决定降为候选或移出，不附任何内容
- **THEN** 格式正确
- **WHEN** 决定降为候选或移出，附基准关注论点作为论点更新，或者附基准跟进申请
- **THEN** 都是格式错误

#### Scenario: 关注不能选别的状态的决定

- **WHEN** 关注的结论的决定是持有、加仓、清仓或升级
- **THEN** 都是格式错误

#### Scenario: 什么变了的格式

- **WHEN** 决定继续关注、降为候选或移出，什么变了写"财报推迟到下月"
- **THEN** 都格式正确
- **WHEN** 决定继续关注，什么变了是 "  "
- **THEN** 格式错误
- **WHEN** 决定开仓方案，写基准方案条款，附基准投资论点，什么变了写"财报推迟到下月"
- **THEN** 格式错误

### Requirement: 结论的校验

PM 提交结论以后，调度器 SHALL 按下表的顺序检查，给出第一项不通过的原因；全部通过才算有效。不通过的原因作为结果返回，由调用方退回 PM。

| 顺序 | 检查 | 不通过时的原因 |
| --- | --- | --- |
| 1 | 结论的种类是案件类型对应的（见「案件类型」的"结论"列） | 结论不属于这个案件 |
| 2 | 跟进案件的结论没有附跟进申请 | 跟进案件不能再申请跟进 |
| 3 | 结论新写的关注论点（升级、清仓转为关注、关注的论点更新）有承诺（stock-pool spec「关注论点的格式」） | 关注论点缺少承诺 |
| 4 | 复查类案件里，决定是持有、加仓、减仓或继续关注时附了论点更新（续期，下一个复查日以及催化剂到期后新的催化剂都写在里面） | 续期缺少论点更新 |
| 5 | 关注复查和关注催化剂复查里，到上限（见「续期上限」）时决定不是继续关注 | 续期次数已用完 |
| 6 | 入场条件满足开出的关注股事件和关注催化剂复查里，决定不是开仓方案时写了什么变了 | 没有写什么变了 |
| 7 | 事件案件：本案件向事件类别要求的子 agent 派过任务 | 缺少事件要求的子 agent |
| 8 | 决定是开仓方案或加仓时：结论里信号的评分大于 0 | 开仓评分不大于 0 |
| 9 | 决定是开仓方案、加仓或升级时：引用的 Result 里，状态是完成的来自至少"研究要求的子 agent 数"（默认 2）个不同子 agent | 研究不足 |

- 调用方传入：案件类型（事件案件带要求的子 agent 和事件类别）、结论、本案件派过任务的子 agent、本案件状态是完成的 Result 各自出自哪个子 agent、是否到上限。没传入的 Result（状态不是完成，或者不是本案件的）不计数
- 第 3 项只检查新写的论点：继续关注不附论点更新时，现在的论点里有没有承诺都通过
- 第 4 项只检查附了论点更新；复查日和催化剂截止日期是不是新的、取值是否合理，由「复查日与催化剂」检查
- 复盘案件不唤醒 PM，校验复盘案件的结论 SHALL 报错

#### Scenario: 结论不属于这个案件

- **WHEN** 持仓风险事件提交关注的结论（继续关注）；寻股提交候选的结论（保持）；候选评估提交寻股的结论
- **THEN** 都被拒绝，原因是"结论不属于这个案件"
- **WHEN** 关注跟进提交关注的结论（继续关注）
- **THEN** 通过

#### Scenario: 跟进案件不能再申请跟进

- **WHEN** 持仓跟进提交持仓的结论：持有，附基准跟进申请
- **THEN** 被拒绝，原因是"跟进案件不能再申请跟进"
- **WHEN** 关注跟进提交关注的结论：继续关注，附基准跟进申请
- **THEN** 被拒绝，原因是"跟进案件不能再申请跟进"
- **WHEN** 持仓事件提交持仓的结论：持有，附基准跟进申请
- **THEN** 通过

#### Scenario: 复查案件续期要附论点更新

- **WHEN** 持仓复查提交持仓的结论：持有，不附论点更新
- **THEN** 被拒绝，原因是"续期缺少论点更新"
- **WHEN** 持仓复查提交持仓的结论：持有，附基准投资论点作为论点更新
- **THEN** 通过
- **WHEN** 持仓催化剂复查提交持仓的结论：减仓（60 股、市价单），不附论点更新
- **THEN** 被拒绝，原因是"续期缺少论点更新"
- **WHEN** 关注催化剂复查提交关注的结论：继续关注，不附论点更新
- **THEN** 被拒绝，原因是"续期缺少论点更新"
- **WHEN** 关注复查提交关注的结论：继续关注，附基准关注论点作为论点更新
- **THEN** 通过

#### Scenario: 不续期的决定不用附论点更新

- **WHEN** 持仓复查提交持仓的结论：清仓，去向移出；关注复查提交关注的结论：降为候选；关注复查提交关注的结论：开仓方案（基准方案条款、基准投资论点）
- **THEN** 都通过

#### Scenario: 不是复查类案件不要求续期

- **WHEN** 持仓事件提交持仓的结论：持有，不附论点更新；持仓跟进提交持仓的结论：持有，不附论点更新
- **THEN** 都通过

#### Scenario: 缺少事件要求的子 agent

- **GIVEN** BBB 的公告事件开出的关注股事件（要求 Fundamentals）
- **WHEN** 本案件只向 News 和 Quant 派过任务，提交关注的结论：继续关注
- **THEN** 被拒绝，原因是"缺少事件要求的子 agent"
- **WHEN** 本案件还向 Fundamentals 派过任务，它的 Result 是超时
- **THEN** 通过

#### Scenario: 非事件案件不要求派任务

- **WHEN** 候选评估没有派过任何任务，提交候选的结论：保持，不引用 Result
- **THEN** 通过

#### Scenario: 研究要求的边界

- **WHEN** 关注股事件提交关注的结论：开仓方案（基准方案条款、基准投资论点），引用 R-1（News）和 R-2（Quant）
- **THEN** 通过
- **WHEN** 同上，只引用 R-1
- **THEN** 被拒绝，原因是"研究不足"
- **WHEN** 同上，引用 R-1 和 R-3，R-3 也出自 News，状态是完成
- **THEN** 被拒绝，原因是"研究不足"

#### Scenario: 状态不是完成的 Result 不算

- **GIVEN** 本案件还有 R-4，出自 Fundamentals，状态是无信号，没有作为完成的 Result 传入
- **WHEN** 关注股事件提交关注的结论：开仓方案，引用 R-1 和 R-4
- **THEN** 被拒绝，原因是"研究不足"

#### Scenario: 加仓和升级也有研究要求

- **WHEN** 持仓事件提交持仓的结论：加仓（基准方案条款），只引用 R-1
- **THEN** 被拒绝，原因是"研究不足"
- **WHEN** 候选股事件提交候选的结论：升级（基准关注论点），只引用 R-2
- **THEN** 被拒绝，原因是"研究不足"
- **WHEN** 同上两个结论，都引用 R-1 和 R-2
- **THEN** 都通过

#### Scenario: 其他决定没有研究要求

- **WHEN** 持仓事件提交持仓的结论：持有、减仓（60 股、市价单）、清仓（去向移出），都不引用 Result；候选评估提交候选的结论：保持、移出，都不引用 Result；寻股提交寻股的结论：加入 DDD（评分 1），不引用 Result
- **THEN** 都通过

#### Scenario: 多项不通过时给出第一项

- **WHEN** 持仓复查提交持仓的结论：加仓（基准方案条款），不附论点更新，只引用 R-1
- **THEN** 被拒绝，原因是"续期缺少论点更新"
- **GIVEN** BBB 的新闻事件开出的关注股事件（要求 News），本案件只向 Quant 派过任务，状态是完成的 Result 只有 R-2
- **WHEN** 提交关注的结论：开仓方案（基准方案条款、基准投资论点），只引用 R-2
- **THEN** 被拒绝，原因是"缺少事件要求的子 agent"
- **WHEN** 持仓跟进提交关注的结论：继续关注，附基准跟进申请
- **THEN** 被拒绝，原因是"结论不属于这个案件"

#### Scenario: 复盘案件没有结论

- **WHEN** 校验每周复盘或卖出复盘的任何结论
- **THEN** 都报错

#### Scenario: 开仓评分的边界

- **WHEN** 关注股事件提交关注的结论：开仓方案（基准方案条款、基准投资论点），信号是评分 1 的信号
- **THEN** 通过
- **WHEN** 同上，信号是评分 0 的信号；或者评分 -1 的信号
- **THEN** 都被拒绝，原因是"开仓评分不大于 0"

#### Scenario: 加仓的评分

- **WHEN** 持仓事件提交持仓的结论：加仓（基准方案条款），信号是评分 1 的信号
- **THEN** 通过
- **WHEN** 同上，信号是评分 0 的信号；或者评分 -1 的信号
- **THEN** 都被拒绝，原因是"开仓评分不大于 0"

#### Scenario: 其他决定不看评分

- **WHEN** 持仓事件提交持仓的结论：持有、减仓（60 股、市价单）、清仓（去向移出），信号都是评分 -2 的信号
- **THEN** 都通过
- **WHEN** 关注股事件提交关注的结论：继续关注，信号是评分 0 的信号
- **THEN** 通过
- **WHEN** 候选股事件提交候选的结论：升级（基准关注论点），信号是评分 0 的信号
- **THEN** 通过
- **WHEN** 寻股提交寻股的结论：加入 DDD（评分 0）
- **THEN** 通过

#### Scenario: 评分排在研究要求之前

- **WHEN** 关注股事件提交关注的结论：开仓方案（基准方案条款、基准投资论点），信号是评分 0 的信号，只引用 R-1
- **THEN** 被拒绝，原因是"开仓评分不大于 0"

#### Scenario: 新写的关注论点要有承诺

- **WHEN** 关注复查提交关注的结论：继续关注，论点更新是基准关注论点去掉承诺
- **THEN** 被拒绝，原因是"关注论点缺少承诺"
- **WHEN** 候选评估提交候选的结论：升级，关注论点是基准关注论点去掉承诺
- **THEN** 被拒绝，原因是"关注论点缺少承诺"
- **WHEN** 持仓事件提交持仓的结论：清仓，去向转为关注，关注论点是基准关注论点去掉承诺
- **THEN** 被拒绝，原因是"关注论点缺少承诺"
- **WHEN** 上面三个结论的关注论点都是基准关注论点
- **THEN** 都通过

#### Scenario: 不写新论点时不看承诺

- **GIVEN** BBB 现在的关注论点没有承诺
- **WHEN** BBB 的新闻事件开出的关注股事件提交关注的结论：继续关注，不附论点更新
- **THEN** 通过

#### Scenario: 到上限不能继续关注

- **GIVEN** 到上限
- **WHEN** 关注复查或关注催化剂复查提交关注的结论：继续关注，附基准关注论点作为论点更新
- **THEN** 都被拒绝，原因是"续期次数已用完"
- **WHEN** 关注复查提交关注的结论：降为候选；移出；开仓方案（基准方案条款、基准投资论点）
- **THEN** 都通过

#### Scenario: 没到上限可以继续关注

- **GIVEN** 没到上限
- **WHEN** 关注复查提交关注的结论：继续关注，附基准关注论点作为论点更新
- **THEN** 通过

#### Scenario: 上限只管复查类案件

- **GIVEN** 到上限
- **WHEN** BBB 的新闻事件开出的关注股事件提交关注的结论：继续关注
- **THEN** 通过
- **WHEN** 关注跟进提交关注的结论：继续关注
- **THEN** 通过

#### Scenario: 入场条件满足时不开仓要写什么变了

- **GIVEN** BBB 的入场条件满足开出的关注股事件，本案件向 Quant 派过任务
- **WHEN** 提交关注的结论：继续关注；降为候选；移出，都不写什么变了
- **THEN** 都被拒绝，原因是"没有写什么变了"
- **WHEN** 同上三个结论，都写什么变了"财报推迟到下月"
- **THEN** 都通过
- **WHEN** 提交关注的结论：开仓方案（基准方案条款、基准投资论点），引用 R-1 和 R-2
- **THEN** 通过

#### Scenario: 催化剂复查不开仓要写什么变了

- **WHEN** 关注催化剂复查提交关注的结论：继续关注，附基准关注论点作为论点更新，不写什么变了
- **THEN** 被拒绝，原因是"没有写什么变了"
- **WHEN** 同上，写什么变了"催化剂到期没有兑现"
- **THEN** 通过
- **WHEN** 关注催化剂复查提交关注的结论：降为候选，不写什么变了
- **THEN** 被拒绝，原因是"没有写什么变了"

#### Scenario: 其他关注案件不用写什么变了

- **WHEN** 关注复查提交关注的结论：继续关注，附基准关注论点作为论点更新；关注跟进提交关注的结论：继续关注
- **THEN** 都通过，都不用写什么变了
- **WHEN** BBB 的新闻事件开出的关注股事件，本案件向 News 派过任务，提交关注的结论：继续关注
- **THEN** 通过

#### Scenario: 观望的检查排在研究之前

- **GIVEN** BBB 的入场条件满足开出的关注股事件，本案件没有派过任务
- **WHEN** 提交关注的结论：继续关注，不写什么变了
- **THEN** 被拒绝，原因是"没有写什么变了"
- **GIVEN** 到上限
- **WHEN** 关注催化剂复查提交关注的结论：继续关注，附基准关注论点作为论点更新，不写什么变了
- **THEN** 被拒绝，原因是"续期次数已用完"
