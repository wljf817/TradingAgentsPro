## ADDED Requirements

### Requirement: 查询历史的动作

`query_history` 每执行一次（history-query spec「查询工具」）SHALL 写一条查询历史：行为者是 Agent 网关，对象是查询的股票，案件 ID 是调用所属的案件。

| 项 | 内容 |
| --- | --- |
| 输出的引用 | 返回的案件的 ID |
| 说明 | 起始日和案件类型，没有的写不限；截止时刻（UTC）；案件和交易各返回几条、总数几条；已实现盈亏合计 |
| 耗时、token、费用 | 空 |

查询次数用完时工具不执行，SHALL NOT 写。

#### Scenario: 查询历史

- **WHEN** K-1 按 2026-10-14 15:00Z 的快照查询 BBB，起始日 2026-10-09，返回 K-11、K-13 和 1 笔交易，案件总数 2，交易总数 1，合计 -456.00
- **THEN** 程序日志有一条查询历史：行为者 Agent 网关，对象 BBB，案件 K-1，输出的引用 K-11、K-13，说明写明起始日 2026-10-09、案件类型不限、截止时刻 2026-10-14 15:00:00 UTC、案件 2 / 2、交易 1 / 1、合计 -456.00
- **AND** 耗时、token 和费用为空

#### Scenario: 次数用完不写

- **GIVEN** 查询次数上限 n，一次运行里模型调用 n + 1 次
- **WHEN** 调用 K-1 的 PM
- **THEN** 程序日志有 n 条查询历史
