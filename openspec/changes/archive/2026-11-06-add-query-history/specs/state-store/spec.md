## ADDED Requirements

### Requirement: 读取某个时刻的版本

按一个时刻 T 读取一张版本表时，SHALL 给出每个键写入时刻早于 T 的最新版本，再按筛选列的值筛选。T 以前还没有版本的键没有这一项；筛选看的是这个版本的值，不是最新版本的值。结果按键排序。读写出错时照「读写出错时报错」处理。

场景里的记录都是止损保护，按股票保存。

#### Scenario: 按时刻读版本

- **GIVEN** AAA 的记录 2026-10-13 20:00Z 写入有效，2026-10-14 16:00Z 写入失效；BBB 的记录 2026-10-14 18:00Z 第一次写入有效
- **WHEN** 按 2026-10-14 17:00Z 读取
- **THEN** 有 AAA 有效的版本，没有 BBB

#### Scenario: 筛选看那时的版本

- **GIVEN** AAA 的记录 2026-10-13 20:00Z 写入有效，2026-10-14 16:00Z 写入失效
- **WHEN** 按 2026-10-14 15:00Z 读取，只要有效的
- **THEN** 有 AAA
- **WHEN** 按 2026-10-14 17:00Z 读取，只要有效的
- **THEN** 没有 AAA

#### Scenario: 写入时刻等于 T

- **GIVEN** AAA 的记录只在 2026-10-14 15:00Z 写入过
- **WHEN** 按 2026-10-14 15:00Z 读取
- **THEN** 没有 AAA
