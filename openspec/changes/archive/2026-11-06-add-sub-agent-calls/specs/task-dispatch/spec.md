## MODIFIED Requirements

### Requirement: 子 agent 的输出变成 Result

调用方 SHALL 把子 agent 的输出（信号、无信号或者输出不合法）、已知的条目（signal-format spec「子 agent 引用的条目」）、这个任务的费用和实际使用的模型（model-fallback spec「实际使用的模型」）交给 Agent 网关，"现在"是收到输出的时刻。不晚于截止时间收到时，网关 SHALL 按 signal-format spec「收到输出时的校验」「子 agent 引用的条目」检查，按下表生成 Result，Result 的模型就是调用方给出的实际使用的模型；晚于截止时间的见「超时」，Result 没有模型：

| 收到的输出 | Result |
| --- | --- |
| 合法的信号 | 完成，输出是这个信号 |
| 合法的无信号 | 无信号，输出是这个无信号 |
| 输出不合法（结构错误） | 失败，原因是格式不合法，说明是输出不合法的原因，指出是哪一项、为什么 |
| 格式正确的信号，评估窗口或数据截至时刻不通过 | 失败，原因是格式不合法，说明是 signal-format spec 给出的原因 |
| 格式正确的信号或无信号，引用了未知的条目 | 失败，原因是格式不合法，说明是 signal-format spec 给出的原因 |

格式不合法的 Result 就是这个任务最终的 Result：SHALL NOT 重新调用子 agent，也不切换备用模型；发起者可以之后再派（失败的不复用，见「相同的任务」）。

本 requirement 的场景里，已知的条目有 E-1 和 E-2。

#### Scenario: 收到合法的信号和无信号

- **GIVEN** PM 派发价格请求（T-1）
- **WHEN** 2026-10-14 15:01:30Z 收到 s-1 给出的基准信号
- **THEN** T-1 完成，输出是基准信号，模型是 s-1、不是备用模型
- **WHEN** 同样的时刻收到 s-1 给出的基准无信号
- **THEN** T-1 是无信号，输出是基准无信号，模型是 s-1

#### Scenario: 备用模型给出的输出

- **GIVEN** PM 派发价格请求（T-1）
- **WHEN** 2026-10-14 15:03:00Z 收到 s-2 给出的基准信号
- **THEN** T-1 完成，模型是 s-2、是备用模型

#### Scenario: 结构错误

- **GIVEN** PM 派发价格请求（T-1）
- **WHEN** 2026-10-14 15:01:30Z 收到 s-1 给出的缺少主要风险的基准信号
- **THEN** T-1 失败，原因是格式不合法，说明指出缺少主要风险，模型是 s-1
- **WHEN** 同样的时刻收到输出不合法，原因"没有调用交回工具"
- **THEN** T-1 失败，原因是格式不合法，说明"没有调用交回工具"，模型是 s-1

#### Scenario: 评估窗口不在配置的选项里

- **GIVEN** PM 派发价格请求（T-1）
- **WHEN** 2026-10-14 15:01:30Z 收到 s-2 给出的评估窗口 4 的信号
- **THEN** T-1 失败，原因是格式不合法，说明是"评估窗口不在配置的选项里"，模型是 s-2、是备用模型

#### Scenario: 数据截至时刻晚于收到的时刻

- **GIVEN** PM 派发价格请求（T-1）
- **WHEN** 2026-10-14 15:01:30Z 收到数据截至 2026-10-14 15:01:31Z 的信号
- **THEN** T-1 失败，原因是格式不合法，说明是"数据截至时刻晚于现在"
- **WHEN** 同样的时刻收到数据截至 2026-10-14 15:01:30Z 的信号
- **THEN** T-1 完成

#### Scenario: 引用了未知的条目

- **GIVEN** PM 派发价格请求（T-1）
- **WHEN** 2026-10-14 15:01:30Z 收到 s-1 给出的引用 E-1 和 E-9 的信号；或者收到引用 E-9 的无信号
- **THEN** T-1 都失败，原因是格式不合法，说明写明未知的条目 E-9，模型是 s-1

#### Scenario: 晚于截止时间收到的不记模型

- **GIVEN** PM 派发价格请求（T-1，截止时间 2026-10-14 15:05:00Z）
- **WHEN** 2026-10-14 15:05:01Z 收到 s-1 给出的基准信号
- **THEN** T-1 超时，没有输出，也没有模型
