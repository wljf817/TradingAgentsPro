# Spec Delta

## MODIFIED Requirements

### Requirement: 通过后立即预留

风控 SHALL 在检查方案的同一次操作里完成预留：结论为通过或调整时，按最终股数为这个方案新建预留；结论为拒绝时不预留。

- 开仓类方案（买入、加仓）的预留是开仓预留，占用资金、持仓名额、板块额度和风险额度
- 减仓类方案（减仓、清仓）的预留是卖出预留，占用卖出股数

后续方案检查时，全部有效预留都计入额度，计入方式见 risk-rules spec「其他方案的预留计入额度」。

本 spec 用到的几个量：

- 预留股数：风控给出的最终股数
- 累计成交股数：这个方案的订单到目前为止一共成交的股数，从 0 开始
- 剩余股数：预留股数减去累计成交股数
- 有效预留：没有释放、剩余股数大于 0 的预留；其他预留都已结束

本 spec 的场景除非另有说明，都使用 risk-rules spec 的默认阈值和基准数据：

- 每笔佣金为 0，不用默认值；佣金的场景另外写明每笔佣金
- 当前时刻 2026-10-14 15:00Z（盘中），交易日历是纽交所日历
- 权益 100,000；已结算资金 40,000
- 持仓 AAA：板块"科技"，100 股，均价 100，最新价 110，止损价 90
- 没有预留；单日亏损熔断没有触发；不处于降级模式
- 基准方案：买入 BBB，板块"医疗"，100 股，限价单，限价 50，止损价 45（需要资金 5,025，计划风险 525）

#### Scenario: 通过后预留，后续方案按剩余额度检查

- **GIVEN** 基准数据，已结算资金改为 10,050
- **WHEN** 检查基准方案
- **THEN** 结论为通过，BBB 有一份 100 股的开仓预留
- **WHEN** 再检查买入 CCC：板块"能源"，150 股，限价 50，止损价 48
- **THEN** 结论为调整，最终股数 100，原因是"已结算资金"（只剩 10,050 − 5,025 = 5,025）
- **AND** CCC 有一份 100 股的开仓预留
- **WHEN** 再检查买入 DDD：板块"能源"，10 股，限价 50，止损价 45
- **THEN** 结论为拒绝，原因是"已结算资金"
- **AND** DDD 没有预留

#### Scenario: 退出方案预留卖出股数

- **GIVEN** 基准数据
- **WHEN** 检查减仓 AAA：60 股，市价单
- **THEN** 结论为通过，AAA 有一份 60 股的卖出预留
- **WHEN** 再检查清仓 AAA，市价单
- **THEN** 结论为通过，最终股数 40
