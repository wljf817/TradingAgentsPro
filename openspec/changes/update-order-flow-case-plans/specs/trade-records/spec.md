# Spec Delta

## MODIFIED Requirements

### Requirement: 交易记录的内容

执行模块 SHALL 为每笔订单和每张止损单各记一条交易记录，键是客户端订单 ID。内容如下：

| 项 | 买单、卖单 | 止损单 |
| --- | --- | --- |
| 客户端订单 ID | 方案 ID | 止损单的客户端订单 ID，比如 BBB-STOP-1 |
| 类型 | 买单是买入，卖单是卖出 | 止损单 |
| 股票 | 订单的 | 止损单的 |
| 来源方案 ID | 订单的方案 ID | 这只股票止损价来自的开仓订单的方案 ID：最近创建的、累计成交大于 0 的开仓订单（见 stop-protection spec「止损价」）；没有这样的订单时没有 |
| 来源案件 ID | 订单的来源案件（order-lifecycle spec「提交订单」）；没有时没有 | 来源方案的订单的来源案件，也就是开仓或加仓的案件；没有来源方案、或者来源方案的订单没有来源案件时没有 |
| 委托股数 | 订单的委托股数 | 止损单的未成交股数加累计成交股数 |
| 累计成交股数、成交均价、累计费用 | 订单的 | 止损单的 |
| 状态 | 订单的状态 | 见「止损单交易记录的状态」 |
| 创建时刻 | 订单的创建时刻 | 止损单的创建时刻 |
| 成交日、结算日 | 见「成交日和结算日」 | 同左 |

本 spec 的场景除非另有说明，都使用 order-lifecycle spec「提交订单」的基准数据，以及 stop-protection spec「止损单」里的方案和说法，另外：

- P1 的再校验结果里生效的紧急阈值是 0.08；P2 的是 0.06
- P5：减仓 AAA 60 股，市价单；再校验通过，最终股数 60，生效的有效期是当天收盘
- 券商账户：权益 100,000，现金 40,000，前一交易日收盘时的权益 101,000。现金已经包含当天卖出成交的钱
- "券商回报 P1 变为……"没写累计费用时，累计费用是 0
- "券商回报 BBB-STOP-1 变为……"指之后按客户端订单 ID 查询时，券商给出的这张止损单的状态、未成交股数、止损价、累计成交股数、成交均价和累计费用；没写累计成交和累计费用时都是 0
- "读取账户数据"指在当时的时刻向执行模块要账户数据

#### Scenario: 买单的交易记录

- **GIVEN** 基准数据
- **WHEN** 提交 P1，券商受理，没有成交
- **THEN** P1 的交易记录：买入 BBB，来源方案 P1，没有来源案件，委托 100 股，累计成交 0，没有成交均价，累计费用 0，已提交，创建时刻 2026-10-14 15:00Z，没有成交日和结算日

#### Scenario: 卖单的交易记录

- **GIVEN** 基准数据
- **WHEN** 提交 P5，券商回报 P5 变为全部成交、累计成交 60、成交均价 101、累计费用 2，跟进 P5
- **THEN** P5 的交易记录：卖出 AAA，来源方案 P5，委托 60 股，累计成交 60，成交均价 101，累计费用 2，全部成交，成交日 2026-10-14，结算日 2026-10-15

#### Scenario: 止损单的交易记录

- **GIVEN** P1 已经提交，订单已提交
- **WHEN** 券商回报 P1 部分成交、累计成交 30、成交均价 49.90，券商持仓变为 30 股，2026-10-14 15:00Z 跟进 P1，券商受理止损单
- **THEN** BBB-STOP-1 的交易记录：止损单，BBB，来源方案 P1，委托 30 股，累计成交 0，已提交，创建时刻 2026-10-14 15:00Z，没有成交日和结算日

#### Scenario: 加仓成交后，止损单的来源方案换成加仓方案

- **GIVEN** 持有 BBB 100 股，止损单已对齐，P2 已经提交，订单已提交
- **WHEN** 券商回报 P2 部分成交、累计成交 20，券商持仓变为 120 股，跟进 P2
- **THEN** 券商收到 BBB-STOP-1 的改单：120 股，止损价 48
- **AND** BBB-STOP-1 的交易记录：来源方案 P2，委托 100 股（改单还没生效）
- **WHEN** 券商回报 BBB-STOP-1 变为挂着、未成交 120 股、止损价 48，对齐 BBB
- **THEN** BBB-STOP-1 的交易记录：来源方案 P2，委托 120 股

#### Scenario: 案件的方案的交易记录带来源案件

- **GIVEN** 基准数据
- **WHEN** 提交 P1，来源案件是 K1，券商受理
- **THEN** P1 的交易记录的来源案件是 K1
- **WHEN** 券商回报 P1 部分成交、累计成交 30，券商持仓变为 30 股，跟进 P1，券商受理止损单
- **THEN** BBB-STOP-1 的交易记录：来源方案 P1，来源案件 K1

#### Scenario: 加仓的案件换成止损单的来源案件

- **GIVEN** 持有 BBB 100 股，开仓订单 P1 的来源案件是 K1，止损单已对齐；P2 已经提交，来源案件是 K2，订单已提交
- **WHEN** 券商回报 P2 部分成交、累计成交 20，券商持仓变为 120 股，跟进 P2
- **THEN** BBB-STOP-1 的交易记录：来源方案 P2，来源案件 K2
