## MODIFIED Requirements

### Requirement: 取新闻

模块 SHALL 按调用方给出的一组股票、起始时刻和可选的结束时刻，向新闻源取起始时刻（含）以来发布、标注了这些股票中至少一只的新闻，给了结束时刻时只取结束时刻（含）以前发布的，然后：

- 把还没存过的新闻存下：按新闻 ID 判断，已经存过的 MUST NOT 再写入，也 MUST NOT 修改已经存下的那条，内容变了也一样
- 返回这次新存下的新闻，按发布时刻排序，发布时刻相同的按新闻 ID 排序
- 新闻源这次给出的结果里同一个新闻 ID 出现几次，只存一次、返回一次
- 没有给出股票时，结果为空，不向新闻源取
- 同一只股票给出多次，只向新闻源问一次
- 新闻源超时、断线、限频或出错时，报数据源不可用，这次什么都不存；模块不重试，下一次调用再取

#### Scenario: 第一次取

- **GIVEN** 新闻源对 AAA、BBB 给出 N2、N1；还没有存过新闻
- **WHEN** 取 AAA、BBB 自 2026-10-14 00:00Z 的新闻
- **THEN** 新闻源被问到的是 AAA、BBB，起始时刻 2026-10-14 00:00Z
- **AND** 存下 N1、N2，返回 N1、N2，按这个顺序

#### Scenario: 再取一次只返回新的

- **GIVEN** 已经存过 N1；新闻源给出 N1、N2
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 存下 N2，返回只有 N2
- **AND** N1 仍然只存了一次

#### Scenario: 存过的新闻后来被改了

- **GIVEN** 已经存过 N1，标题"AAA raises guidance"；新闻源给出新闻 ID 101，标题改成了"UPDATE: AAA raises guidance"
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 返回为空
- **AND** 读到的 101 的标题仍是"AAA raises guidance"

#### Scenario: 同一条新闻在结果里出现两次

- **GIVEN** 新闻源给出 N1、N1
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 存下 N1 一条，返回 N1 一条

#### Scenario: 没有给出股票

- **WHEN** 取新闻，没有给出任何股票
- **THEN** 结果为空
- **AND** 没有向新闻源取

#### Scenario: 同一只股票给出多次

- **WHEN** 取 AAA、AAA、BBB 自 2026-10-14 00:00Z 的新闻
- **THEN** 新闻源被问到一次，股票是 AAA、BBB

#### Scenario: 新闻源不可用

- **GIVEN** 新闻源这次报数据源不可用
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 的新闻
- **THEN** 报数据源不可用
- **AND** 什么都没有存，新闻源只被问了一次

#### Scenario: 给出结束时刻

- **GIVEN** 新闻源对 AAA 给出 N1
- **WHEN** 取 AAA 自 2026-10-14 00:00Z 到 2026-10-14 12:00Z 的新闻
- **THEN** 新闻源被问到的是 AAA，起始时刻 2026-10-14 00:00Z，结束时刻 2026-10-14 12:00Z
- **AND** 存下 N1，返回 N1

## ADDED Requirements

### Requirement: 按新闻 ID 读一条新闻

模块 SHALL 能按新闻 ID 读出已经存下的那条新闻；没有时结果为空，不向新闻源取。

#### Scenario: 读到

- **GIVEN** 已经存下 N1
- **WHEN** 读新闻 ID 101
- **THEN** 读到 N1，和存下的完全相同

#### Scenario: 没有这条

- **GIVEN** 已经存下 N1
- **WHEN** 读新闻 ID 999
- **THEN** 结果为空
