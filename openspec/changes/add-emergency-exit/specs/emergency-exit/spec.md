# Spec Delta

## Purpose

紧急退出在常规交易时段内判定：持仓当天跌幅达到 PM 设的紧急阈值时清仓这只股票，组合单日亏损达到熔断线时清仓全部持仓，并给出代码触发的清仓方案和当天的熔断状态。

## ADDED Requirements

### Requirement: 判定的时机和输入

紧急退出 SHALL 根据以下输入判定，给出判定结果：

- 全部持仓，每只包含：
  - 股票、板块
  - 生效的紧急阈值：这只股票最近一次有成交的开仓方案的生效紧急阈值，见 risk-rules spec
  - 前一交易日收盘价、最新价：来自行情，没有行情时为空
  - 今天开仓成交的均价：当前交易时段里，这只股票的买入或加仓订单有成交时，这笔订单的成交均价；没有时为空
- 当前权益、前一交易日收盘时的权益
- 当前时刻和交易日历
- 配置

只在常规交易时段内判定（开盘 ≤ 当前时刻 < 收盘）。当前时刻不在常规交易时段内时，判定结果为空，熔断也不会因此触发。

判定结果是要清仓的股票清单，每只股票最多出现一次，带代码触发的清仓方案（见「代码触发的清仓方案」）和原因：

| 熔断状态 | 清单 | 原因 |
| --- | --- | --- |
| 已触发 | 全部持仓 | 组合熔断 |
| 没有触发 | 触及个股跌幅的持仓 | 个股跌幅 |

熔断状态按这次判定之后的算，见「组合熔断」「熔断状态」。调用方可以随时重复判定。

本 spec 的场景除非另有说明，都使用默认配置和下面的基准数据：

- 当前时刻 2026-10-14 15:00Z（周三，盘中），交易日历是纽交所日历，这一天的常规交易时段是 13:30Z 到 20:00Z
- 前一交易日收盘时的权益 100,000，当前权益 99,000
- 持有两只股票，今天都没有开仓成交：
  - AAA：板块"科技"，紧急阈值 0.08，前一交易日收盘价 100，最新价 95
  - BBB：板块"医疗"，紧急阈值 0.10，前一交易日收盘价 50，最新价 49
- "判定"指在当前时刻用这些数据判定一次；"结果为空"指判定结果里没有股票
- "AAA 的清仓方案"指交易日 2026-10-14、股票 AAA 的代码触发的清仓方案

#### Scenario: 没有触发时结果为空

- **GIVEN** 基准数据
- **WHEN** 判定
- **THEN** 结果为空

#### Scenario: 盘前不判定，开盘后的第一个价格就判定

- **GIVEN** 基准数据，当前时刻 2026-10-14 12:00Z（盘前），AAA 最新价 80
- **WHEN** 判定
- **THEN** 结果为空
- **WHEN** 当前时刻 2026-10-14 13:30Z（开盘），AAA 最新价仍是 80，判定
- **THEN** 结果是 AAA，原因是"个股跌幅"，带 AAA 的清仓方案

#### Scenario: 收盘时刻和盘后不判定

- **GIVEN** 基准数据，AAA 最新价 80，当前权益 90,000
- **WHEN** 当前时刻分别是 2026-10-14 20:00Z（收盘）和 21:00Z（盘后），各判定一次
- **THEN** 结果都为空
- **AND** 熔断状态都是没有触发

#### Scenario: 没有持仓

- **GIVEN** 基准数据，没有持仓
- **WHEN** 判定
- **THEN** 结果为空

### Requirement: 个股跌幅

一只持仓的跌幅 =（参考价 − 最新价）÷ 参考价。跌幅大于或等于这只股票的紧急阈值时，这只股票 SHALL 触及个股跌幅。参考价如下：

| 情况 | 参考价 |
| --- | --- |
| 今天没有开仓成交 | 前一交易日收盘价 |
| 今天有开仓成交 | 今天开仓成交的均价 |

最新价为空，或者参考价为空（今天没有开仓成交、前一交易日收盘价也为空）时，不判定这只股票的个股跌幅，它不会触及个股跌幅。最新价高于参考价时跌幅为负，不会触及。

#### Scenario: 跌幅等于紧急阈值时触发

- **GIVEN** 基准数据，AAA 最新价 92（跌幅 0.08）
- **WHEN** 判定
- **THEN** 结果是 AAA，原因是"个股跌幅"，带 AAA 的清仓方案

#### Scenario: 跌幅小于紧急阈值时不触发

- **GIVEN** 基准数据，AAA 最新价 92.01（跌幅 0.0799）
- **WHEN** 判定
- **THEN** 结果为空

#### Scenario: 每只股票用自己的紧急阈值

- **GIVEN** 基准数据，AAA 最新价 91，BBB 最新价 45.5，两只的跌幅都是 0.09
- **WHEN** 判定
- **THEN** 结果只有 AAA，原因是"个股跌幅"（AAA 的紧急阈值 0.08，BBB 的是 0.10）

#### Scenario: 今天有开仓成交时从成交均价算

- **GIVEN** 基准数据，AAA 今天开仓成交的均价 92
- **WHEN** AAA 最新价 85，判定（从成交均价算跌幅约 0.076；从前一交易日收盘价算是 0.15）
- **THEN** 结果为空
- **WHEN** AAA 最新价 84.64，判定（从成交均价算跌幅 0.08）
- **THEN** 结果是 AAA，原因是"个股跌幅"

#### Scenario: 今天开仓成交价高于前一交易日收盘价时同样从成交均价算

- **GIVEN** 基准数据，AAA 今天开仓成交的均价 105
- **WHEN** AAA 最新价 96.6，判定（从成交均价算跌幅 0.08；从前一交易日收盘价算只有 0.034）
- **THEN** 结果是 AAA，原因是"个股跌幅"

#### Scenario: 没有行情时不判定个股跌幅

- **GIVEN** 基准数据，AAA 最新价为空
- **WHEN** 判定
- **THEN** 结果为空
- **WHEN** AAA 最新价 80，前一交易日收盘价为空，判定
- **THEN** 结果为空
- **WHEN** AAA 最新价 84，前一交易日收盘价为空，今天开仓成交的均价 92，判定（跌幅约 0.087）
- **THEN** 结果是 AAA，原因是"个股跌幅"

### Requirement: 组合熔断

单日亏损 = 前一交易日收盘时的权益 − 当前权益；熔断线 = 前一交易日收盘时的权益 × 熔断比例。判定时单日亏损大于或等于熔断线，熔断 SHALL 触发。

当前权益包括现金，所以单日亏损包括今天已经卖出的部分。熔断触发以后清仓全部持仓，不看个股跌幅，也不看有没有行情。

#### Scenario: 单日亏损等于熔断线时触发

- **GIVEN** 基准数据，当前权益 97,000（单日亏损 3,000，熔断线 3,000）
- **WHEN** 判定
- **THEN** 结果是 AAA 和 BBB，原因都是"组合熔断"，分别带 AAA 和 BBB 的清仓方案
- **AND** 熔断状态是已触发

#### Scenario: 单日亏损小于熔断线时不触发

- **GIVEN** 基准数据
- **WHEN** 当前权益分别是 97,000.01 和 105,000（盈利），各判定一次
- **THEN** 结果都为空
- **AND** 熔断状态都是没有触发

#### Scenario: 同时触及个股跌幅的股票只出现一次

- **GIVEN** 基准数据，当前权益 97,000，AAA 最新价 90（跌幅 0.10）
- **WHEN** 判定
- **THEN** 结果是 AAA 和 BBB 各一次，原因都是"组合熔断"

#### Scenario: 熔断时没有行情的持仓照样清仓

- **GIVEN** 基准数据，当前权益 97,000，BBB 的前一交易日收盘价和最新价都为空
- **WHEN** 判定
- **THEN** 结果是 AAA 和 BBB，原因都是"组合熔断"

#### Scenario: 没有持仓时熔断照样触发

- **GIVEN** 基准数据，没有持仓，当前权益 97,000
- **WHEN** 判定
- **THEN** 结果为空
- **AND** 熔断状态是已触发

### Requirement: 熔断状态

紧急退出 SHALL 给出当前时刻的熔断状态：一个交易时段里有一次判定使熔断触发，从这次判定的时刻起，到这个交易时段收盘之前，熔断状态都是"已触发"；其他任何时刻都是"没有触发"，包括从来没有判定过的时候。

已触发期间，权益回升到熔断线以内也不解除，之后的每次判定都清仓全部持仓。收盘以后形成的方案在下一个交易日执行，那一天的熔断没有触发。风控检查和下单前再校验输入的"单日亏损熔断是否已经触发"使用这个状态。

#### Scenario: 触发以后到收盘一直保持

- **GIVEN** 基准数据，当前权益 97,000，判定，熔断触发
- **WHEN** 当前时刻 2026-10-14 16:00Z，当前权益 99,500，只持有 BBB，判定
- **THEN** 结果是 BBB，原因是"组合熔断"
- **AND** 熔断状态仍是已触发
- **WHEN** 当前时刻 2026-10-14 19:59Z
- **THEN** 熔断状态仍是已触发

#### Scenario: 收盘后解除

- **GIVEN** 基准数据，当前权益 97,000，判定，熔断触发
- **WHEN** 当前时刻分别是 2026-10-14 20:00Z（收盘）、2026-10-15 12:00Z（下一个交易日盘前）
- **THEN** 熔断状态都是没有触发
- **WHEN** 当前时刻 2026-10-15 15:00Z，前一交易日收盘时的权益 97,000，当前权益 96,500，判定
- **THEN** 结果为空
- **AND** 熔断状态是没有触发

#### Scenario: 还没有判定过

- **GIVEN** 紧急退出刚刚新建，还没有判定过
- **WHEN** 当前时刻 2026-10-14 15:00Z，查询熔断状态
- **THEN** 熔断状态是没有触发

### Requirement: 代码触发的清仓方案

紧急退出 SHALL 能为一只股票和一个交易日生成代码触发的清仓方案，内容如下：

| 字段 | 取值 |
| --- | --- |
| 方案 ID | 由股票和交易日确定：股票和交易日都相同时，方案 ID 相同；有一项不同时，方案 ID 不同 |
| 股票、板块 | 这只持仓的 |
| 动作 | 清仓 |
| 股数 | 不填，卖出全部可卖数量 |
| 订单类型 | 市价单 |
| 限价、止损价、紧急阈值、有效期、允许价格偏离 | 都不填；生效的有效期由风控给出默认值，见 risk-rules spec |

判定结果里的方案，交易日是判定时所在交易时段的交易日。本地备用止损触发后，也用这只股票和当前交易日生成清仓方案。所以同一只股票在同一个交易日最多只有一个代码触发的清仓方案：重复判定时得到同一个方案，风控和执行模块按方案 ID 不会重复预留、重复下单；这个方案结束以后（成交、被拒、过期），当天不会再有新的。

#### Scenario: 清仓方案的内容

- **GIVEN** 基准数据，AAA 最新价 92
- **WHEN** 判定
- **THEN** AAA 的清仓方案是：股票 AAA，板块"科技"，清仓，不填股数，市价单，不填限价、止损价、紧急阈值、有效期和允许价格偏离

#### Scenario: 同一交易日重复判定得到同一个方案

- **GIVEN** 基准数据，AAA 最新价 92，判定
- **WHEN** 当前时刻 2026-10-14 15:05Z，AAA 最新价 91，再判定一次
- **THEN** 两次结果里 AAA 的清仓方案相同，方案 ID 相同

#### Scenario: 股票或交易日不同时方案 ID 不同

- **WHEN** 分别生成交易日 2026-10-14 的 AAA、交易日 2026-10-15 的 AAA、交易日 2026-10-14 的 BBB 的清仓方案
- **THEN** 三个方案 ID 互不相同

#### Scenario: 本地备用止损和紧急退出得到同一个方案

- **GIVEN** 基准数据，AAA 最新价 92，判定
- **WHEN** 为 AAA（板块"科技"）和交易日 2026-10-14 生成清仓方案
- **THEN** 和判定结果里 AAA 的清仓方案相同

### Requirement: 紧急退出配置

紧急退出的阈值 SHALL 是可配置项，默认值如下：

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| 熔断比例 | 0.03 | 单日亏损达到前一交易日收盘时的权益的 3% 时熔断 |

熔断比例必须大于 0 且小于 1，否则配置报错。

#### Scenario: 默认配置

- **WHEN** 不传任何配置项新建配置
- **THEN** 熔断比例是 0.03

#### Scenario: 熔断比例超出范围

- **WHEN** 熔断比例分别为 0 和 1
- **THEN** 配置报错

#### Scenario: 改熔断比例

- **GIVEN** 基准数据，熔断比例 0.05
- **WHEN** 当前权益 97,000，判定
- **THEN** 结果为空，熔断状态是没有触发
- **WHEN** 当前权益 95,000，判定
- **THEN** 结果是 AAA 和 BBB，原因都是"组合熔断"
