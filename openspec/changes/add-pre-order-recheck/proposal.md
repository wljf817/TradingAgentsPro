# Proposal

## Why

方案从首次风控检查到下单之间，要经过人工确认，盘后形成的方案还要等开盘，可能隔了几分钟到一整夜。首次检查用的是案件快照里的数据，到下单时，价格可能已经跳空，持仓可能已经被止损卖掉，资金和熔断状态也可能变了。按旧数据下单，会买在跳空之后，或者买入后立刻触发止损，或者卖出已经不存在的持仓。

变更 2 和变更 3 已经把规则和预留做成了可以重跑的样子，但还没有下单前的这道检查。本变更的目的只有一个：**提交订单前用实时数据再校验一次方案：超过有效期、价格偏离过大或跌破止损价就作废；否则按实时数据重跑风控，结果决定按多少股下单，预留随之更新。**

引用的 Proposal（完整版）章节：

- 「风控引擎与执行」的"下单前再校验"：重新读取实时报价、券商持仓和可用资金，重跑一次风控；方案带有效期和允许的价格偏离，超过就作废并退回 PM
- 「风控引擎与执行」的"交易时段"：只在常规交易时段下单；盘前盘后形成的方案，有效期要覆盖到下一个开盘，开盘时由再校验检查跳空
- 「风控引擎与执行」的"额度预留"：方案作废时释放预留
- 「架构」的"风控与执行"：再校验在人工确认之后、执行模块下单之前

## What Changes

- 交易方案 `TradePlan` 增加两个可选字段：
  - 有效期：四种动作都可以填
  - 允许价格偏离：只有买入和加仓可以填
- 风控结果 `RiskDecision` 增加生效的有效期：通过或调整时才有。方案没填时，默认到执行交易日收盘
- 风控增加一条开仓类规则「允许价格偏离」：生效的允许价格偏离要在配置的范围内，方案没填时用默认值。配置增加对应的下限、上限和默认值
- 风控用例增加再校验，输入是方案 ID、实时账户数据、实时最新价和熔断状态，只能在常规交易时段调用：
  - 下面三种情况方案作废：已经超过有效期；开仓类方案的实时价偏离限价超过允许价格偏离；开仓类方案的实时价不高于止损价
  - 都没有发生时，按实时数据重跑风控。方案自己的预留不计入额度；请求股数是首次检查的最终股数，清仓是实时的可卖数量
  - 结果是通过或调整时，按这个股数下单，预留改为这个股数；结果是拒绝时，方案作废并释放预留
  - 已经结束的方案（被拒绝、已释放、已作废）再校验时，结果是拒绝，原因是"方案已结束"
- 检查和再校验共用"一次只处理一个方案"的约束
- 测试替身不需要新增，沿用变更 3 的内存预留存储和测试时钟

## Non-goals

- 读取券商的实时持仓、资金和报价，再和状态库的板块、止损价、最近成交日拼成账户数据：M2 接 moomoo 时实现。本变更的再校验接收调用方传入的数据
- 谁在什么时候调用再校验（确认之后马上调用，或者等到开盘再调用）：M2 的下单工作流
- 方案作废后怎么退回 PM，以及调整后的通知里怎么标明：M2 的人工确认和 M3/M4 的案件流程
- 订单按有效期撤单：变更 5 的订单状态机。本变更只在风控结果里给出生效的有效期
- 紧急风险退出要不要走再校验：变更 8，见「需要人决定」
- 再校验结果写入程序日志和状态库：程序日志在 M4，状态库方案在 M2 确定

## Capabilities

### New Capabilities

- `pre-order-recheck`：再校验的时机和输入、有效期、价格偏离、跌破止损价、按实时数据重跑风控、预留随结果更新、已结束的方案

### Modified Capabilities

- `risk-rules`：
  - 「交易方案的格式」增加有效期和允许价格偏离
  - 「风控的输入和判定」的结果增加生效的有效期
  - 「开仓类规则」增加「允许价格偏离」
  - 「风控阈值配置」增加允许价格偏离的下限、上限和默认值
- `risk-reservations`：「一次只检查一个方案」扩展到再校验

## 需要人决定

已决定（2026-10-03，人同意推荐做法）：

1. **有效期和允许价格偏离由谁定**：Proposal 说每个方案都带这两项，没说不填时怎么办。决定：两项都写进方案，可以不填
   - 有效期不填时，到执行交易日收盘为止。盘后形成的方案的执行交易日是下一个交易日，所以自动覆盖到下一个开盘，满足"交易时段"的要求
   - 允许价格偏离不填时用默认值 0.03。和紧急阈值一样，首次检查时要在下限 0.01 和上限 0.10 之间，防止填一个很大的值，让这项检查失效
2. **退出方案要不要查价格偏离**（变更 2「需要人决定」第 6 条）：偏离过大就作废会阻塞退出，和"保证退出不被阻塞"矛盾，而且市价单的退出方案没有方案价格。决定：只有开仓类方案因为价格偏离作废；退出方案只查有效期，再重跑减仓类规则
3. **重跑风控的结果是调整或拒绝时怎么办**（变更 2「需要人决定」第 7 条）：决定拒绝就作废，释放预留，退回 PM；调整就按更小的股数下单，预留随之缩小，在通知里标明，不重新人工确认。首次检查的调整要进入人工确认，再校验的调整不需要，因为它只会让人确认过的股数变少
4. **跳空低开到止损价以下**：Proposal 只写了价格偏离。实时价已经不高于止损价、但还没超过允许偏离时（比如止损价离限价只有 2%），规则全部能通过，买入后会立刻被止损。决定：开仓类方案的实时价不高于止损价就作废
5. **偏离和哪个价格比**：Proposal 只说"实时价格偏离方案价格"。决定：用实时最新成交价和方案的限价比，偏离 = |实时价 − 限价| ÷ 限价，涨和跌都算，等于允许偏离时不作废

留给后续变更（到时候再定）：

6. （变更 8）「通用规则」说所有交易方案都要经过再校验。紧急风险退出是代码生成的市价单，再校验只剩有效期和可卖数量两项。倾向：走同一个再校验入口，有效期用默认值
