# Spec Delta

## MODIFIED Requirements

### Requirement: 系统故障

案件 SHALL 能在任何运行中的阶段（包括复盘）因系统故障结束，结束原因是系统故障。系统故障包括：PM 或 Reviewer 的调用失败（Agent 网关返回失败，比如主模型和备用模型全部超时或不可用）、开仓类方案的 Critic 不可用（见「Critic 不可用」）、风控检查或下单流程出错。

- 系统故障 SHALL NOT 被当作投资判断：故障发生在结论通过校验以前的，案件没有结论；以后的，结论仍然算数，只是方案不执行
- 调用预算用完不是系统故障：Agent 网关不因为预算用完拒绝运行中案件的调用，开始了的案件照常运行到结束（call-budget spec「已经开始的案件」）

#### Scenario: PM 的调用失败

- **GIVEN** CCC 的持仓复查在唤醒 PM
- **WHEN** PM 的主模型和备用模型都超时，Agent 网关返回失败
- **THEN** 结束：系统故障，没有结论

#### Scenario: PM 回应时调用失败

- **GIVEN** 开仓案件被质询一次，在 PM 回应
- **WHEN** PM 的调用失败
- **THEN** 结束：系统故障，有结论

#### Scenario: 风控和下单流程出错

- **GIVEN** 开仓案件在风控；另一种情况下退出案件在等下单
- **WHEN** 风控检查出错；下单流程出错
- **THEN** 都结束：系统故障，有结论
